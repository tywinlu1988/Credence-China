## 走查：LGD 五级分类 + 外部支持评估

**场景**：某 AA 级城投发行人，拟发行 5 年期中票，由当地 AAA 级城投集团提供担保。以下对照
lgd-recovery-framework §二/§四/§五 与 external-support-framework §三/§四 逐步走查。

### 第一部分：LGD 五级分类评估（lgd-recovery-framework §二 + §四）

1. **债项优先级确认（§五）**：该中票为无担保普通债券（senior unsecured），处于一般清偿顺序，
   优先级序列为有担保债权 > 职工薪酬/税费 > 普通债权 > 次级债。✔
2. **增信措施识别（§五 + §六）**：该债项由 AAA 级城投集团提供**保证担保**（连带责任），
   担保方信用质量高于发行人自身。按 §六 抵押物分类框架，保证担保归类为外部信用增级，
   不涉及具体抵押物估值。✔
3. **LGD 基准定位（§二）**：根据 §二 五级分类体系——LGD1（<10% 预期损失率）对应有足额
   高质量抵押/担保的债项；LGD2（10-25%）对应有增信但增信质量中等的债项；LGD3（25-50%）
   对应无增信普通债项；LGD4（50-75%）对应次级/劣后债项；LGD5（>75%）对应预期几乎全损。
   本债项有 AAA 级集团担保 → 定位于 LGD1–LGD2 区间（担保方评级 AAA 为高质量增信）。
   示例结论：**LGD2**（有增信、增信质量高但非现金/政府债券类足额抵押）。✔
4. **回收率估算（§十一 简化估算方案）**：在公开数据约束下，结合行业特征（城投类，
   §八 行业特征：基础设施/公用事业类资产有一定残值但流动性受限）与担保增信，
   示例估算回收率区间为 50-70%（中心估计约 60%）。✔
5. **预期损失矩阵定位（§一 1.2）**：结合 WP-M0-01 主体 PD 评级（AA，示例评级），
   查预期损失矩阵——AA 级×LGD2 对应预期损失率约 0.5-1.5%（示例读数，矩阵数值指针至
   lgd-recovery-framework §一 表）。✔

### 第二部分：外部支持评估（external-support-framework §三 + §四）

1. **支持方识别**：该发行人属于区县级城投，实际控制人为当地财政局。
   潜在支持方为：① 地方政府（区县级）；② 控股股东（AAA 级城投集团）。✔
2. **支持能力评估（§三）**：
   - **地方政府支持能力**：该区县一般公共预算收入 ~30 亿元（示例读数），政府债务率 ~80%
     （示例读数），财力中等偏低。按 §三 地方政府支持能力评级框架定位为中低能力（示例评级）。
     ✔
   - **集团股东支持能力**：AAA 级城投集团总资产 ~800 亿元（示例读数），资产负债率 ~65%，
     支持能力强。✔
3. **支持意愿评估（§四）**：
   - **战略重要性**：该发行人为区域内唯一的基础设施投融资平台，承担多个在建重点项目，
     战略重要性高。→ **支持意愿强**。✔
   - **声誉风险**：若该发行人违约，将对区域融资环境造成重大负面影响（城投板块声誉传导）。
     → **进一步强化支持意愿**。✔
4. **支持能力×意愿二维矩阵定位**：综合评估——地方政府支持能力中低但意愿强，
   集团股东支持能力+意愿均强。按 §四 二维矩阵规则，综合支持评估为**较强**（示例结论）。
   ✔
5. **支持上调幅度建议（§五 评级调整规则）**：外部支持较强 → 建议在主体评级基础上
   上调 1-2 子级（示例结论，具体上调幅度以 external-support-framework §五
   评级调整映射表为单一事实源）。✔

### 第三部分：分析汇总

| 模块 | 评估项 | 示例结论 |
|---|---|---|
| LGD 评估 | LGD 等级 | **LGD2**（有 AAA 集团担保，预期损失率 10-25% 区间） |
| LGD 评估 | 回收率估计 | **50-70%**（中心估计 ~60%，简化估算指针 §十一） |
| LGD 评估 | 预期损失矩阵 | AA 级×LGD2 → 预期损失率 ~0.5-1.5%（示例，指针 §一 表） |
| 外部支持 | 地方政府支持能力 | 中低（区县级财力中等、债务率 ~80%，示例） |
| 外部支持 | 集团股东支持能力 | 强（AAA 级、资产规模大、杠杆适中，示例） |
| 外部支持 | 综合支持评估 | **较强**（意愿强+能力中强组合，示例二维矩阵结论） |
| 外部支持 | 评级上调建议 | 主体评级基础上上调 **1-2 子级**（示例，指针 §五） |

### 交付物渲染（Type 8 + Type 9）

report 阶段以 template-type8.html **LGD 评估报告** 渲染：LGD 五级分类结果以
档位卡片形式展示（LGD1–LGD5 标色对应严重度），增信措施逐项列出，担保方信用评估、
回收率估算以表格呈现。template-type9.html **外部支持评估报告** 渲染：支持方识别→
支持能力评估→支持意愿评估→二维矩阵定位→上调建议，逐段可见、有据可查。两份报告
各自独立成篇、内容完整，分别对应 registry outputs `[LGD等级+回收率, 外部支持调整建议]`。✔
