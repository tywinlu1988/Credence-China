# 马赛克引擎

**版本**: v0.12.0-release | **日期**: 2026-07-10
**核心原则**: 承认数据永远残缺，把"残缺"从弱点变成产品特征

---

## 一、核心理念

### 1.1 两个基础理论

| 理论 | 含义 | 在引擎中的体现 |
|---|---|---|
| **马赛克理论** | 单块公开数据碎片无意义，拼在一起构成完整画像。每一片公开信息——政策文件、法院公告、招标结果、价格周报——单独看都不能说明问题，但聚合后形成判断 | 多源数据聚合 → 信号叠加 → 置信度加权 |
| **信息完备性理论** | 不仅回答"知道了什么"，更回答"还不知道什么"。信息缺口不是缺陷，而是风险信号的来源——"我们没有这个数据"本身就是在告诉用户"这个维度存在不确定性" | 每个分析结论附带数据完备性评分和缺口列表 |

### 1.2 马赛克引擎在整体架构中的位置

```
技能包 v0.3.0
  ├── 行业分类（十维评分）
  ├── 轨道A：基本面分析（金字塔框架）
  ├── 轨道B：市场定价（四级信号）
  ├── 交叉对撞（四象限矩阵）
  ├── 黑天鹅回溯验证
  │
  └── 马赛克引擎层 ← 本文档
        ├── 信号提取层
        ├── 马赛克拼图层
        ├── 完备性评估层
        └── 模式B接口定义（占位）
```

## 三、信号提取层

### 3.1 功能

**输入**：WebSearch返回的搜索结果（标题+摘要+URL）
**输出**：结构化信号对象

### 3.2 信号数据结构

```yaml
signal:
  id: "sig-001"
  source_url: "https://..."
  source_type: "policy_document" | "court_record" | "bidding_result" | "industry_report" | "news"
  timestamp: "2026-06-15"  # 信息来源的时间，不是抓取时间
  dimension: "L2_technology"  # 属于金字塔哪一层
  content: "隆基BC电池量产效率达24.8%"
  direction: "positive" | "negative" | "neutral"
  strength: 1-5  # 1=弱方向性信号, 5=明确量化信号
  cross_validated: false  # 进入拼图层后若有≥2独立源确认则改为true
```

### 3.3 提取规则

- LLM从每条搜索结果的标题+摘要中提取信号
- **不做判断，只做结构化**
- 最多返回3条信号/源
- 每片数据都标注其所属的信号置信度层级

### 3.4 信源可信度分级

本节内容归并自 qualitative-analysis.md §2.1-2.4，v0.11.2 起本节为单一事实源。

**刻度区分**：本节 L1-L6 是**信源可信度**（信息来源本身的可靠性等级）；§4.2 的 L1-L5 是**信号置信度**（信号经交叉验证后的确认强度）——两套刻度独立使用，不做直接换算。

所有进入分析流程的信息源，必须按照以下六级体系标注可信度。**未标注可信度的信号不进入马赛克拼图流程**。

| 级别 | 名称 | 特征 | 时效性 | 可信度 | 适用场景 |
|------|------|------|--------|--------|---------|
| **L6** | 政府官方公告 | 国务院、发改委、工信部、央行、财政部等官方发布；红头文件格式；可追溯原文 | 即时发布，但传导至企业需1-12个月 | ★★★★★ 极高 | 行业政策方向、监管规则变更、产业支持力度 |
| **L5** | 产业协会/权威第三方 | 中国光伏行业协会(CPIA)、中国汽车工业协会、中国有色金属工业协会；PVInfoLink/TrendForce/SMM等专业机构；中债登/上清所登记数据 | 周度-月度发布 | ★★★★☆ 高 | 行业统计数据、价格走势、装机/出货量 |
| **L4** | 券商/研究机构研报 | 中信、中金、华泰等头部券商研究所报告；行业深度报告、调研纪要 | 月度-季度 | ★★★☆☆ 中高 | 行业深度分析、企业调研信息、竞争格局判断 |
| **L3** | 正规媒体/财经新闻 | 财新、证券时报、21世纪经济报道、第一财经、经济观察报等持牌财经媒体；交易所公告转载 | 即时-日度 | ★★★☆☆ 中等 | 企业动态跟踪、行业新闻、政策解读 |
| **L2** | 企业自愿披露 | 上市公司公告、业绩说明会纪要、企业官网新闻、路演材料、ESG报告 | 按披露规则（季度/半年度/年度） | ★★☆☆☆ 中低 | 企业战略、经营数据、管理层判断 |
| **L1** | 匿名来源/传闻/社交媒体 | 雪球/东方财富股吧帖子、微信公众号未认证文章、微信群截图、未具名人士透露 | 即时（但不可验证） | ★☆☆☆☆ 低 | ⚠️ 仅作为线索，**不得单独作为判断依据** |

**准入规则：**

```
L6-L4信号 → 可直接进入马赛克拼图层（经时效性检查后）
L3-L2信号 → 必须标注来源级别，需≥2条独立验证方可升级为有效信号
L1信号   → 仅用于生成"需关注方向"，不得作为评分依据
           标注格式："传闻：[内容] — 来源不可验证，需进一步核实"
```

**每级信源的典型陷阱与规避：**

| 信源级别 | 典型陷阱 | 规避方法 |
|---------|---------|---------|
| **L6 政府公告** | 政策意图和实际效果之间存在偏差（"政策温差"）；部委文件与地方执行脱节 | 必须追踪至地方执行层面；关注部委后的省级配套文件是否落地 |
| **L5 行业协会/第三方** | 样本偏差（CPIA仅覆盖主要企业，中小企业数据缺失）；统计口径变化 | 检查统计口径是否一致；关注"样本企业"范围变化 |
| **L4 券商研报** | 利益冲突（投行关系、自营持仓）；乐观偏差；跟风共识 | 查看研报评级分布（若某券商对某行业所有企业均为"买入"→警惕）；对比多家券商结论 |
| **L3 正规媒体** | 追逐热点导致的信息放大；转载过程中的信息失真（"传话损失"） | 追溯到原文/源头公告；警惕"据知情人士透露"类表述 |
| **L2 企业自愿披露** | 选择性披露（好消息及时公布、坏消息拖延）；措辞修饰（"行业性挑战"=亏损） | 对比不同时期的披露措辞变化；关注"应披露未披露"事项 |
| **L1 匿名来源** | 恶意做空/做多动机；信息不完整导致的误导 | 仅用于"需关注"清单，不用于评分；如果有L4+级别交叉验证方可升级 |

**交叉验证规则：** 单一信号不可作为判断依据。所有关键判定需经交叉验证。

| 验证类型 | 规则 | 示例 |
|---------|------|------|
| **同级别交叉** | 2个独立L4+源指向同一事实 | 中信+中金两份研报均提到"某企业组件出货量Q2环比下降15%" |
| **跨级别交叉** | L6+L4或L5+L3指向同一方向 | 发改委政策文件+L6 + 券商解读+L4 = 政策方向确认 |
| **上下级联合** | L6官方公告 + L5行业数据验证影响 | 光伏补贴退坡政策公布 + CPIA数据显示装机增速下降 |
| **反方向验证** | 主动寻找反方向证据——"什么情况下这个判断会错" | 判断"行业下行"时，检查是否有超预期的积极政策信号 |

**交叉验证状态标注：**

| 状态 | 含义 | 在报告中的表示 |
|------|------|--------------|
| ✅ 已验证 | ≥2个独立源（可跨级别）确认同一事实 | 信号置信度升级 |
| ⏳ 部分验证 | 1个源 + 1个方向性一致的弱信号 | 标注"部分验证" |
| ⚠️ 待验证 | 仅1个源，无独立交叉验证 | 标注"待验证"，该信号不纳入评分 |
| 🔴 矛盾 | 多个源指向不同方向 | 进入矛盾信号处理流程 |

**矛盾信号处理规则：** 当不同来源的信号指向相反方向时，按照以下优先级处理：

```
Step 1：检查信源级别差异
  ├── L6/L5 vs L2 → 优先相信L6/L5（除非有特定理由怀疑官方数据）
  ├── L4 vs L4   → 检查是否存在利益冲突，无冲突时视作"意见分歧"
  └── L3 vs L6   → 以L6为准，标注"媒体解读与官方文件有出入"

Step 2：检查时间戳差异
  ├── 较新信号 vs 较旧信号 → 优先较新信号（标注时效性差异）
  └── 但：旧信号是官方公告、新信号是传闻 → 优先旧信号

Step 3：升级验证
  ├── 矛盾无法解决 → 标注为"该维度存在显著分歧"
  ├── 影响评级精度 → 评分区间加宽（±1 → ±2）
  └── 如果分歧涉及一票否决条件 → 升级为最高优先级处理

Step 4：输出规范
  输出格式：
  [维度名称] — 信号矛盾
  ├── 信号A：[内容] — 来源：[级别] — 时间戳
  ├── 信号B：[内容] — 来源：[级别] — 时间戳
  ├── 矛盾原因分析：[分析]
  ├── 优先选择：[选择逻辑]
  └── 残余不确定性：[区间]
```

**矛盾信号处理实例（结论指针）**：光伏行业2026年装机预测中，CPIA（L5）预测220-260GW，某头部券商（L4）预测180-200GW并给出并网瓶颈论据。处理结论：按信源级别L5优先——以CPIA区间220-260GW为基准，附加"券商提及的并网瓶颈可能导致实际值落于区间下沿"的下行风险标注。（实例的完整数据表随源文档归档，此处保留结论。）

## 四、马赛克拼图层

### 4.1 核心逻辑

```
对于每个分析维度（如L1政策环境）：
  1. 汇总该维度的所有信号
  2. 同方向信号叠加 → 增加置信度
  3. 矛盾信号出现 → 标注"分歧"并降低置信度
  4. 跨源交叉验证 → 提升信号层级
  5. 计算该维度的"信号密度" = 有效信号数 / 该维度应有信号数的预估
```

### 4.2 五级信号置信度

| 级别 | 类型 | 含义 |
|---|---|---|
| **L5** | 多源交叉验证信号 | 同一事实被≥2个独立来源确认 |
| **L4** | 单源直接信号 | 一个可靠来源明确陈述 |
| **L3** | 衍生推断信号 | 从多片碎片组合推理得出 |
| **L2** | 方向性弱信号 | 只有方向，没有量级 |
| **L1** | 缺失信号（缺口） | 应该有的数据没有——风险信号 |

**层级优先级**：L5多源交叉验证 > L4单源直接信号 > L3衍生推断 > L2方向性弱信号 > L1缺口（单独标注）。

### 4.3 信号密度指标

信号密度是马赛克拼图层**最关键的输出**——直接回答"我们对这个维度了解多少"。

| 信号密度 | 含义 | 对最终评分的影响 |
|---|---|---|
| **>80%** | 信息充分——关键信号基本齐全 | 高置信度，可直接给出评分 |
| **50-80%** | 信息中等——主要信号有但细节不足 | 中置信度，评分附带±1的误差区间 |
| **20-50%** | 信息不足——只有碎片 | 低置信度，标注为"待补充"，仅给出方向性判断 |
| **<20%** | 信息严重缺失 | 不给出该维度评分，标注为"信息不足无法评估" |

### 4.4 叙事过滤

本节内容归并自 qualitative-analysis.md §5.4，v0.11.2 起本节为单一事实源。

中国信用市场存在大量"市场叙事"——广泛传播但未经验证的集体信念。拼图层的核心能力之一是从叙事中分离事实。

**常见市场叙事清单：**

| 市场叙事 | 对应行业 | 叙事分析 | 信源级别警示 |
|---------|---------|---------|-------------|
| "国家半导体舰队" | 半导体 | 国家支持但不代表个体企业不会违约——紫光集团已被验证 | L4-L2信号被过度解读为L6级确定性 |
| "国企信仰" | 所有国企 | 国企身份不保证不违约——永煤已被验证 | L6（国企身份）被错误关联到信用质量 |
| "大而不倒" | 各行业龙头 | 规模大不代表不会出风险——恒大已被验证 | 规模指标(L2)被错误解读为安全信号 |
| "赛道好所以企业好" | 高景气行业 | 繁荣行业里也有亏损企业——光伏行业2025年过半亏损 | 行业信号(L5)被错误映射到个体企业(L2) |
| "IPO过会=信用背书" | 拟上市公司 | IPO通过不代表财务真实性被确认 | L2（招股书）被错误赋值为高于其实际可信度 |
| "技术领先=护城河" | 科技企业 | 技术领先可能被快速追赶——专利的时间窗口有限 | L2技术数据被过誉 |

**叙事检查清单（每次输出判断前执行）：**

```
[ ] 这个判断是建立在"公开可验证的事实"还是"行业共识"上？
[ ] 如果撤掉所有媒体报道和券商研报，仅看官方数据和行业数据，结论是否变化？
[ ] 当前市场上大多数人是如何看待这个企业的？我们和主流观点一致还是不同？
[ ] 如果结论与市场共识不同，我们有什么依据支撑逆向判断？
[ ] 有没有"因为所有人都在这么说所以我照搬"的嫌疑？

判定规则：
  若判断主要建立在"行业共识/市场叙事"而非独立交叉验证的事实上 →
    标注"此判断受市场叙事影响，独立事实支撑不足"
    置信度自动降一级
    评分区间加宽（±1 → ±2）
```

**永煤案例——叙事 vs 事实分离（精简）：**

| 叙事层（市场相信的） | 事实层（年报公开数据） |
|--------------------|----------------------|
| "河南国企，AAA评级由政府信用背书" | 母公司负债率94.87%；归母净利润-114.4亿 |
| "短融发行顺利，河南省政府会救助" | 短债占比59.14%（严重短债长投）；关联应收225亿资金被占用 |

**分离操作要点**：将L2（企业年报数据）与L6+L3（市场叙事）分别列示，明确标注"市场共识与公开数据之间存在根本性冲突"→ 以L6+L2为判断基础，L4+L3仅作参考不主导。

## 五、完备性评估层（核心差异化模块）

这是产品差异化的关键。不仅告诉用户"我们看到了什么"，更告诉用户"我们没看到什么，这意味着什么风险"。

### 5.1 每个维度的三要素输出

```
维度：L2 技术路线与竞争位势
├── 信号密度：75%（信息中等）
├── 已获取的关键信号：
│   ├── ✅ 组件量产效率（隆基BC 24.8% vs TOPCon ~23.5%）
│   ├── ✅ 央企集采入围情况（2026年集采59GW数据）
│   ├── ✅ 专利数量（隆基510件 vs 晶科/天合）
│   └── ⚠️ 产能利用率（行业估算值，非企业披露）
├── 缺失的信号：
│   ├── ❌ 各企业的良率数据（企业不单独披露）
│   ├── ❌ 各技术路线的非硅成本精确对比（仅公开估算）
│   └── ❌ BC vs TOPCon在分布式场景的实际发电量对比（无第三方测试）
└── 缺口风险评估：
    → 良率数据缺失 → 无法精确判断成本竞争力 → 评分区间 ±1.5
    → 但央企集采入围数据和效率差距已构成足够的区分信号
```

### 5.2 数据可得性与替代方案登记处

本节归并自 quantitative-analysis.md §1.3、§8.2-8.4，并与本节原"数据缺口→风险映射表"合并去重；v0.11.2 起本节为单一事实源。

#### 5.2.1 数据可得性硬约束（零付费终端环境）

本引擎**不以Wind/Bloomberg等付费终端为必要条件**。以下是零付费终端环境下能做什么、不能做什么的硬约束清单（已合并源文档"数据质量矩阵"与"替代方案汇总表"的重叠行）：

| 指标 | 可得性 | 质量 | 核心局限 | 替代方案/处理 |
|------|--------|------|---------|--------------|
| 到期收益率(YTM)/YTM利差 | 可获取 | 较高 | 非活跃券价格失真；不含权调整 | 交易所行情/中国货币网/和讯债券；仅对活跃券使用（周成交≥1笔） |
| Z-spread | **不可获取** | 不可用 | 需要专业终端的现金流建模引擎 | YTM-同期限国开债（线性插值）近似（⭐⭐⭐ 中等），误差±15-30bp，标注误差 |
| OAS | **不可获取** | 不可用 | 需要含权定价模型 | 不做替代——或对纯债用Z-spread近似，标注不可获取 |
| 修正久期 | 部分可获取 | 中 | 近似计算不含含权调整 | Macaulay Duration近似（D/(1+YTM)）（⭐⭐⭐ 中等，误差随YTM增大）；固定利率纯债可行，可转债/含权债不可用 |
| 凸性 | **不可获取** | 不可用 | 需要精确现金流定价 | 不估算——标注"凸性不可获取" |
| 历史收益率序列 | 可获取（有限） | 中 | 非活跃券缺失，数据稀疏 | 交易所公开行情 |
| 历史波动率(HV) | 可获取（上市公司） | 中高 | 滞后指标；非上市公司不可用 | 配合利差趋势做交叉验证 |
| 隐含波动率 | **不可获取** | 不可用 | 中国信用债/可转债无标准化期权市场 | 用历史波动率(HV_20d)方向性近似（⭐⭐ 低，滞后+精度不足） |
| Bid-ask spread | **不可获取** | 不可用 | 中国债市不透明，做市商报价不可获取 | 日均成交量+换手率作流动性代理（⭐⭐ 低，无法量化交易成本） |
| 股票价格/波动率 | 可获取 | 较高 | — | 免费行情API/财经网站 |
| 成交量/换手率 | 部分可获取 | 中 | 非活跃券数据稀疏 | 活跃券的成交量变化比绝对量更有意义 |
| 信用评级迁移 | 可获取 | 中——滞后性严重 | 评级公司公告，但有滞后性 | 使用轨道A做前瞻验证而非依赖 |
| 北向资金 | 可获取（仅沪港通标的） | 中高 | 精细度不足 | 交易所/港交所每日披露；非港股通标的标记"无数据"，不替代 |
| 融资余额 | 部分可获取（仅两融标的） | 中 | 覆盖有限 | 非两融标的标记"无数据" |
| 发行利率 | 部分可获取（仅有新发时） | 中高 | 不连续 | 二级市场利差作连续替代 |
| 非上市公司财务 | 部分可获取 | 中 | 无公开财报 | 招股书+司法+招标+招聘+工商多源交叉验证（⭐⭐⭐ 中等，取决于数据丰富度） |

**核心结论：在不依赖付费终端的前提下，可以做基于公开市场数据的趋势分析、异常检测、相对价值排序，但不能做需要精确现金流贴现模型和期权定价模型的精细分析。**

#### 5.2.2 公开数据核心局限汇总

| 局限类别 | 具体内容 | 对分析的影响 | 是否可能通过数据源升级解决 |
|---------|---------|-------------|-------------------------|
| **Z-spread/OAS缺失** | 无法获取任何专业终端的利差分解数据 | 无法精细分解信用风险、利率风险和期权风险 | ✅ 接入Wind/Bloomberg后解决 |
| **Bid-ask spread缺失** | 中国债市不透明，做市商报价不可获取 | 无法评估真实交易成本和流动性 | ⚠️ 部分——接入外汇交易中心数据后可能 |
| **非上市公司无股价** | 50%+发债主体是非上市公司 | 波动率分析、股价信号完全不可用 | ❌ 结构性——非上市主体无公开股价 |
| **可转债定价模型缺失** | 不能计算纯债价值、期权价值、理论定价 | 可转债的信用信号提取受限于简化计算 | ✅ 接入专业终端+QuantLib可解决 |
| **中国CDS市场缺失** | 信用违约互换在中国几乎不存在 | 无法从信用衍生品中提取信用风险溢价 | ❌ 市场基础设施问题——非数据获取 |
| **ES/ETL数据不标准** | 无标准化的ESG评分、碳排放数据（公开） | 无法将ESG因子纳入量化模型 | ⚠️ 部分——可接入第三方ESG评分 |
| **高频数据缺失** | 分钟级/逐笔成交数据需付费 | 无法做高频波动率、微观结构分析 | ✅ 接入付费数据后可解决 |
| **非活跃券数据稀疏** | 大量债券数日无成交 | 利差计算失真——基准方法不适用 | ❌ 市场流动性问题——非数据获取 |
| **母子公司数据隔离** | 合并报表掩盖母公司风险（验证案例已反复证实） | 因子分析中的"企业"粒度需要精确到发债主体 | ⚠️ 需要手动识别发债主体——数据源升级不能完全解决 |
| **条款数据非标准化** | 债券条款分散在募集说明书中 | 无法批量做含权分析 | ⚠️ 部分——LLM提取条款后可结构化 |

#### 5.2.3 其余替代方案（未并入 5.2.1 者）

- 个股高频数据 → 日度收盘价+日收益率（⭐⭐⭐ 中等：日度分析足够，无法做微观结构）
- 尾部风险(VaR/ES) → 情景加权法（⭐⭐ 低：仅方向性暴露判断，无统计精度保障）

#### 5.2.4 数据缺口→风险映射表（通用模板）

| 缺口类型 | 典型缺失数据 | 对应的信息风险 | 替代信号 |
|---|---|---|---|
| 竞争数据 | 各企业成本精确对比 | 高估或低估成本优势 | 央企集采中标价（市场接受的溢价） |
| 财务数据 | 非上市企业无公开财报 | 完全无法评估财务健康 | 被执行记录、司法纠纷、招聘趋势 |
| 市场定价 | 非上市企业无股价/债券 | 轨道B完全不可用 | 公开融资事件、股权转让价格 |
| 条款数据 | 无Wind终端无法获取久期/Z-spread | 无法做精细利率风险分析 | YTM近似、同评级利差对比 |
| 流动性数据 | Bid-ask spread在中国不披露 | 无法评估真实交易成本 | 日均成交量、换手率、异常成交量事件 |
| 外部支持 | 地方政府隐性债务真实规模 | 高估或低估政府真实支持能力 | 显性债务率+城投有息负债估算，标注"隐性债务估算误差" |
| 外部支持 | 政府对特定企业的救助承诺（非公开） | 高估支持意愿的确定性 | 历史支持记录+股权结构+战略定位推断，标注"非正式承诺" |
| 外部支持 | 集团内部资金归集政策和实际执行情况 | 无法判断集团对子公司的实际资金支持力度 | 关联方往来款+担保余额+业务协同度，标注"基于公开信息推断" |
| 外部支持 | 战略投资者实际支持意愿（非公开表态） | 高估战投支持的可执行性 | 投资协议条款的公开披露+锁定期+董事会构成 |

### 5.3 完备性评估报告结构

每个分析的输出**必须**包含以下结构：

```
1. 综合评级与核心发现
   └── 置信度标注（高/中/低）

2. 数据完备性报告（信号密度条形图）
   ┌─────────────────────────────────────┐
   │ L1 政策/宏观    ████████░░ 82%      │
   │ L2 技术/竞争    ██████░░░░ 75%      │
   │ L3 供应链/运营  ████░░░░░░ 48% ⚠️   │
   │ L4 财务/偿债    █████████░ 89%      │
   │ L5 外部支持    ██████░░░░ 60% ⚠️   │
   │ 市场定价(轨B)   ███░░░░░░░ 35% ⚠️   │
   │ 相对价值(M1.1)  ██░░░░░░░░ 25% ❌   │
   │ 条款分析(M1.2)  ████████░░ 80%      │
   │ 流动性(M1.3)    ████░░░░░░ 45% ⚠️   │
   └─────────────────────────────────────┘

3. 缺口清单（按影响优先级排序）
   └── 每个缺口包含：具体缺失数据 → 影响 → 替代方案

4. 评分置信区间
   └── 基于信号密度对各维度的评分区间做修正

5. 用户可操作建议
   └── "如需精细相对价值分析，建议接入Wind/Choice数据终端"
```

### 5.4 置信度对评分的影响规则

| 信号密度 | 评分输出规则 |
|---|---|
| >80% | 直接输出精确评分 |
| 50-80% | 输出评分 ±1 区间 |
| 20-50% | 仅输出方向性判断（正面/负面/中性），不输出精确评分 |
| <20% | 标注"信息不足无法评估"，不给出该维度评分 |

**五级置信度子档（归并自 qualitative-analysis.md §7.5）：** 定性判断另使用五级置信度刻度作报告标注——它是上表四档规则的**子档细分**，而非第二套标准：

| 置信度 | 含义 | 适用条件 | 报告标注 | 对应上表档位 |
|-------|------|---------|---------|-------------|
| **高** | 信号充分，趋势明确，多个独立源交叉验证完成 | ≥3个独立L4+级信号指向同一方向，无未解决的矛盾 | 绿色 | >80%档（此子档精确评分可到±0.5粒度） |
| **中高** | 信号较充分，趋势可辨，主要信号已交叉验证 | ≥2个L4+级信号+无致命矛盾，但有1个次要矛盾信号 | 蓝色 | 50-80%档 |
| **中等** | 信号存在但不够充分，方向可辨但幅度不确定 | 1个L4+级信号+1-2个L3级信号，无严重矛盾 | 黄色 | 50-80%档 |
| **中低** | 信号稀疏，方向判断有较大不确定性 | 仅L3及以下信号支撑，或存在未解决的矛盾信号 | 橙色 | 20-50%档（仅输出方向性评分） |
| **低** | 信号严重不足，仅有方向性推测 | 信号密度<30%，或主要判断基于L1-L2信号 | 红色——考虑"不输出此判断" | <20%档（不输出该维度评分） |

评分区间的数值标准一律以本节上表为准——五级刻度仅用于报告标注与输出决策，不产生双标准。

### 5.5 判断级输出规范

本节内容归并自 qualitative-analysis.md §7.1-7.3，v0.11.2 起本节为单一事实源。

分析的输出不是"感觉""判断"——而是带有完整支撑链的结构化结论。**每项判断必须附带以下五个要素：**

```
[判断内容] — 简明的结论性语句

├── 1. 支撑信号列表
│   ├── 信号A：[内容] — 信源级别：[Lx] — 时间戳
│   ├── 信号B：[内容] — 信源级别：[Lx] — 时间戳
│   └── 信号C：[内容] — 信源级别：[Lx] — 时间戳
│
├── 2. 信源可信度综合评估
│   ├── 整体可信度水平：[高/中高/中等/中低/低]
│   ├── 最高质量信号：[哪个信号、什么级别]
│   └── 最弱信号/[疑点]：[哪个信号可能有偏差]
│
├── 3. 交叉验证状态
│   ├── ✅ 已验证：[多少个独立源确认]
│   ├── ⏳ 部分验证：[哪些信号仅有单源]
│   └── ⚠️ 待验证：[哪些信号需进一步核实]
│
├── 4. 不确定性标注
│   ├── 已知的不确定性来源：[具体列出]
│   ├── 对判断的影响程度：[轻微影响/中等影响/可能颠覆判断]
│   ├── 关键数据缺口：[缺失了哪些数据]
│   └── 如果判断错误，最可能的原因：[反向验证思考]
│
└── 5. 时间戳和有效期
    ├── 判断形成时间：[日期]
    ├── 有效期至：[日期]（或"下次财报发布后"）
    └── 触发更新的条件：[什么事件需要更新此判断]
```

（五要素填写实例：§七 通威股份案例的信号清单、交叉验证与缺口标注，即按本节五要素结构组织。）

**禁止输出清单：** 以下类型的输出在任何情况下均不得出现在分析报告中：

| 禁止类型 | 示例 | 为什么禁止 | 应替换为 |
|---------|------|-----------|---------|
| **无支撑断言** | "这家公司资不抵债" | 没有附上支持这个判断的具体数据和来源 | "基于2025年报数据（L2），该公司净资产为-X亿，资产负债率XX%" |
| **无时间戳判断** | "隆基绿能是行业龙头" | 未标注判断的时间依据（龙头地位可能随时间变化） | "截至2025年末，隆基绿能组件出货量位居全球第X位（PVInfoLink/L5）" |
| **不标注不确定性的确定性结论** | "通威肯定会违约" | 信用分析中没有100%的结论 | "基于当前信号（亏损+融资拐点+应收上升），通威的信用质量正在恶化，但违约与否取决于[关键变量]" |
| **主观感受** | "管理层看起来很靠谱" | 无法验证的主观判断 | "管理层在2025年业绩说明会上表示[具体表态]，此前[具体承诺]的实现情况是[结果]" |
| **预测财务数据** | "2026年净利润估计50亿" | 未标注预测依据和假设条件 | "如果组件价格稳定在当前水平（0.8元/W），隆基2026毛利率可能在18-20%（基于[依据]）" |
| **公司股价建议** | "建议买入" | 本引擎做信用分析，不做权益投资建议 | "基于当前利差水平（258bp，高于行业中位数），该债券在光伏行业内处于偏贵区间" |
| **来源模糊的引用** | "有消息称""据业内人士" | 来源不可验证 | 标注确切来源或明确标注L1"匿名来源，不可验证" |
| **评级机构的结论复制** | "外部评级AAA，信用质量好" | 外部评级是输入不是输出，且已知滞后 | 独立分析后的判断，可引用外部评级但需标注已知问题 |

**输出质量检查清单（每次输出判断前必须执行）：**

```
[ ] 每项判断是否已附带支撑信号列表（≥2个独立源）？
[ ] 每个信号是否标注了信源级别（L1-L6）？
[ ] 每个信号是否标注了时间戳？
[ ] 是否标注了交叉验证状态（已验证/部分验证/待验证/矛盾）？
[ ] 是否标注了不确定性来源和影响程度？
[ ] 是否标注了判断有效期和触发更新条件？
[ ] 是否区分了"事实"和"解读"（事实是什么 + 我基于事实判断了什么）？
[ ] 是否排除了市场叙事的影响？（执行 §4.4 叙事检查清单）
[ ] 如果存在矛盾信号，是否解释了矛盾原因和处理方式？
[ ] 是否标注了关键数据缺口？
[ ] 是否避免了所有禁止输出类型？
[ ] 如果涉及预测性判断，是否标注了前置假设条件？
```

### 案例：判断通威股份的偿债能力

**五片碎片——每片单独看都不够：**

| 碎片 | 信号 | 单独看的问题 |
|---|---|---|
| 通威短融2025年利率从2.60%↓2.02%（-58bp） | 市场认为风险在降低 | 可能只是货币环境宽松 |
| 通威短融2026年1月利率从2.02%↑2.15%（+13bp） | 市场开始重新定价风险 | 反弹幅度太小，可能只是噪声 |
| 通威2025年亏损90-100亿 | 基本面严重恶化 | 亏损可能是一次性的（硅料价格暴跌） |
| 通威应收账款从Q3跳升至Q4 | 回款能力在恶化 | 可能只是季节性因素 |
| AAA/稳定评级维持 | 评级机构认为风险可控 | 评级滞后是已知问题 |

**拼在一起后的完整画像：**

```
碎片1（利差压缩） + 碎片2（利差反弹） = 利差拐点信号（弱→中等强度）
碎片2（利差反弹） + 碎片3（巨额亏损） = 市场开始反映基本面（强度升级）
碎片3（亏损） + 碎片4（应收跳升）     = 不仅亏损，回款也在恶化（双杀信号）
碎片5（AAA维持） + 碎片1-4            = 评级滞后确认（评级信号不可信）

马赛克拼图结论：
通威的偿债能力在恶化，市场定价（利差反弹）开始反映这一趋势，
但AAA评级仍在滞后。

信息完备性评估：中等
缺口：通威母公司独立财务数据不可获取
→ 无法精确判断母公司层面的真实偿债能力
```

### 马赛克拼图的过程演示

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 提取5条原始信号 | 各信号单独来看置信度均为L2-L4 |
| 2 | 同方向信号叠加 | 利差先降后升 → 拐点信号（L3→L4升级） |
| 3 | 跨维度交叉验证 | 亏损（L3）+ 应收跳升（L3）= 双杀（L4→L5强制降级） |
| 4 | 矛盾信号处理 | AAA评级 vs 其他4条信号 → 评级信号不可信 |
| 5 | 信号密度计算 | 5维度中有4条可用信号 → 80%（中等偏上） |
| 6 | 缺口识别 | 母公司财务数据缺失 → 影响L4评分置信度±1 |
