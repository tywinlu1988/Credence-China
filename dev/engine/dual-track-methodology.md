## 一、双轨并行架构

分析引擎的核心是**两条独立并行的分析轨道**，在路径末端通过交叉对撞矩阵产生最终判断。

```
输入: 行业 + 企业 + 分析日期
        │
   ┌────┴────────┐
   │              │
轨道A: 基本面   轨道B: 市场定价
(定性+评分)     (量化信号)
   │              │
 L1 (最重层)     Credit Spreads
 L2               Volatility
 L3               Fund Flows
 L4 (最轻层)      Rating Migration
   │              │
   └──────┬───────┘
          ▼
  交叉对撞矩阵
  Consensus → 互相强化
  Divergence → 最有价值的洞察
```

### 两轨设计哲学

| 特征 | 轨道A：基本面 | 轨道B：市场定价 |
|---|---|---|
| 数据来源 | 行业数据、企业财报、政策文件、招投标 | 债券收益率、股票价格、成交量、评级事件 |
| 更新频率 | 季度/年度（财报周期） | 日度/周度（持续更新） |
| 客观性 | 较高（基于公开事实） | 受市场情绪影响 |
| 滞后性 | 存在财报滞后 | 实时反映 |
| 核心价值 | 识别结构性不可持续 | 捕捉市场定价错误 |

### 定性/定量分工与话语权仲裁

归并自 qualitative-analysis.md §1.1-1.2，v0.11.2 起本节为单一事实源。

双轨框架的核心分工：**定性判断方向，定量校准精度**。定性分析回答"信用质量在变好还是变坏"，定量分析回答"变化了多少、市场如何定价"。

| 层级 | 定性负责 | 定量负责 | 最终话语权 |
|------|---------|---------|-----------|
| **趋势判断** | 方向（上行/平稳/下行） | 幅度（+x% / -x%） | 定性——方向错了定量无意义 |
| **异常识别** | "为什么异常" | "是否异常" | 定量——先检测后解释 |
| **归因分析** | "谁在驱动" | "驱动了多少" | 协作——定性锁定因子，定量测量贡献 |
| **预测判断** | "什么情景可能发生" | "每种情景的概率和损失" | 定性——情景构建是判断力问题 |

**核心原则：定性框定可能性的边界，定量在边界内做精确测量。当两者冲突时，优先解决定性问题——方向错了，精度无意义。**

## 二、轨道A：基本面金字塔评分

### 2.1 评分逻辑

每层独立评分（0-10分），权重由行业类型决定。

```
Composite Score = Sigma(Layer Score × Layer Weight)
Layer Score = Sigma(Indicator Score × Indicator Weight)
Indicator Score = f(Raw Value, Threshold, Direction)
```

### 2.2 标准四层金字塔评分

| 行业类型 | L1（最重） | L2 | L3 | L4（最轻） |
|---|---|---|---|---|
| **政策驱动型** | 35% 政策/宏观 | 30% 技术 | 20% 供应链 | 15% 财务 |
| **技术壁垒型** | 20% 政策 | 35% 技术/IP/注册 | 25% 运营 | 20% 财务 |
| **存量博弈型** | 25% 生存位势 | 20% 技术 | 30% 利润要塞 | 25% 财务 |
| **资产租约型** | 15% 政策 | 20% 技术 | 35% 客户/租约 | 30% 财务 |

> **权威源引用**：四层金字塔权重模板的权威定义见[行业分类与分析框架](industry-framework.md) §3.2。本表为复制件，如有差异以industry-framework.md为准。

### 2.3 特殊金字塔结构

| 行业 | 层数 | 层结构及权重 |
|---|---|---|
| **半导体** | 5层 | L1地缘政治30-35%, L2技术25-30%, L3市场15-20%, L4政策/资本10-15%, L5财务5-10% |
| **新能源车-OEM** | 5层 | L1生存位势25%, L2技术20%, L3运营20%, L4财务15%, L5政策/出口10% |
| **新能源车-供应链** | 5层 | L1利润要塞30%, L2技术20%, L3客户质量22%, L4财务17%, L5政策/出口8% |
| **医疗器械** | 5层 | L1政策15%, L2注册证22%, L3渠道25%, L4财务20%, L5外部支持8% |
| **生物医药** | 5层 | L1政策15%, L2管线25%/15%, L3 BD20%/25%, L4财务20%/15%, L5外部支持10%/- |

### 2.4 各层评分示例（光伏）

| 层 | 评分维度 | 高评分（8-10）特征 | 低评分（0-3）特征 |
|---|---|---|---|
| L1 政策 | 政策方向对齐度 | 享受国家级补贴和税收优惠 | 核心产品被政策限制 |
| L2 技术 | 效率差 vs 领先者 | 效率领先行业均值 > 2% | 产能以淘汰技术为主 |
| L3 供应链 | 客户集中度 | 多元化客户分布 | 单一客户 > 50% |
| L4 财务 | 现金/短债比 | > 1.5x | 连续负现金流 + 短债高 |

### 2.5 逐层递进原则

1. **L1必须通过才有意义进入L2。** 如果政策/宏观层面存在致命风险，下层分析无意义。
2. **L4（财务层）是验证层，不是判断层。**
   - 财务状况好但上层差 = **更危险**（可能是财务造假或周期顶部）
   - 财务状况差但上层好 = 标记风险但不颠覆评级
3. **一票否决：** 任一层面触发一票否决条件，综合评级上限锁定为CCC。

## 三、轨道B：市场定价信号

### 3.1 四级市场信号体系

| 级别 | 信用利差 | 波动率 | 资金流向 | 评级事件 |
|---|---|---|---|---|
| **平静（Calm）** | 稳定/收窄 | < 3% 日波动 | 稳定/流入 | 评级稳定 |
| **关注（Watch）** | 走阔20-50bp | 3-5% | 适度流出 | 展望负面 |
| **异常（Abnormal）** | >50bp跳升或持续走阔 | >5% 持续 | 加速流出 | 观察名单 |
| **危机（Crisis）** | 曲线倒挂/冻结 | >8% 或流动性枯竭 | 净清算流出 | 降级 |

### 3.1A 利差计算与异常检测规范

归并自 quantitative-analysis.md §2.1-2.3，v0.11.2 起本节为单一事实源。

> **与 §3.1 的关系**：本节是利差信号的计算与检测方法规范；四级状态（平静/关注/异常/危机）的最终判定阈值以 §3.1 四级信号体系为权威，本节检测结果按 §3.1 口径映射归级。统计校正版本（Bootstrap置信区间/FDR校正）见文末附录"轨道B统计推断规范与输出标准"。

#### 3.1A.1 利差指标定义（Z-spread不可获取约束下的近似体系）

| 指标 | 公式 | 适用场景 | 局限性 |
|------|------|---------|--------|
| **YTM利差** | YTM_债券 - YTM_同期限国开债 | 通用——最基础的信用利差近似 | 未考虑期限结构差异；含权债券偏差大 |
| **YTM-基准利率近似Z-spread** | 同上 + 线性插值修正 | 当待偿期限偏离基准期限时 | 效果中等——方向正确但量级有偏 |
| **行业利差** | YTM利差 - 同评级行业均值 | 跨行业对比时，剔除行业贝塔 | 需要足够样本计算行业均值 |
| **个券-行业偏离度** | 个券YTM利差 - 行业YTM利差中位数 | 识别行业内高于/低于同行的个券 | 样本不足时中位数不稳定 |

**Z-spread的替代处理规则：**

1. 首选：YTM - 同期限国开债收益率（线性插值）
2. 标注："Z-spread不可获取，使用YTM利差近似——分析误差可能随久期和含权特性扩大"
3. 对含权债券单独标注："含权定价依赖OAS模型，无法精确计算"
4. 在结论中使用排序而非绝对值——"利差水平高于80%同行"优于"利差为235bp"

#### 3.1A.2 利差三维对比框架

每个分析对象的信用利差必须在三个维度上展开对比：

```
三维利差分析
  ├── 横向：同行业/同评级企业的利差分布
  │    ├── 目标：识别相对定价——哪些企业被市场高估或低估
  │    └── 输出：个券在行业利差分布中的分位数位置
  ├── 纵向：企业自身历史利差分位数
  │    ├── 目标：判断当前定价相对自身历史是高还是低
  │    ├── 窗口：6个月 / 1年 / 3年（依数据可获取性）
  │    ├── 分位数区间：0-20%压缩 / 20-80%常态 / 80-100%扩张
  │    └── 规则：连续3个月处于80%以上分位数 → 标记为"持续利差扩张"
  └── 交叉：评级间利差补偿
       ├── 目标：判断市场对不同评级的风险溢价是否合理
       ├── 指标：AAA-BBB利差差、BBB-B利差差
       ├── 正常范围：AAA-BBB利差差在80-150bp（历史中位数）
       └── 异常场景：
            ├── 评级间利差差收窄→市场不区分评级，潜在低估风险
            └── 评级间利差差急剧扩大→市场恐慌，流动性溢价主导
```

#### 3.1A.3 利差异常检测规则

| 异常类型 | 定量定义 | 中间信号等级 | 可能含义 |
|---------|---------|-------------|---------|
| **突跳（Jump）** | 单日利差变化 > 50bp | 🔴 异常 | 突发信用事件/评级调整/价格错误 |
| **持续走阔（Trend）** | 连续20+交易日利差累计扩大 > 50bp | 🟡 关注 | 信用质量渐进恶化/行业逆风 |
| **与基本面背离** | 基本面评分稳定但利差走阔 >1个标准差 | 🟠 分歧 | 市场定价与基本面脱节→分歧信号 |
| **与行业背离** | 行业利差稳定个券利差独立走阔 >30bp | 🟠 分歧 | 企业个性化风险暴露 |
| **流动性压缩** | 成交量骤降+利差走阔同时发生 | 🔴 异常 | 流动性危机前兆 |

> **归级仲裁**：上表"中间信号等级"为检测流程的中间标记；映射到平静/关注/异常/危机四级时，以 §3.1 阈值（走阔20-50bp关注、>50bp跳升或持续走阔异常）为最终判定。

**异常检测处理流程：**

```
1. 获取利差时间序列
2. 计算历史均值和标准差（周期=60交易日）
3. 检测条件：
   a) 单日变化 > Mean + 3σ → 突跳异常
   b) 20日累计变化 > Mean + 2σ → 持续异常
   c) 利差分位数 > 90%持续15日 → 高水位预警
4. 交叉验证：同时检查成交量/换手率是否异常
5. 输出：异常信号 + 可能的解释假设 + 建议行动
```

### 3.1B 波动率规范

归并自 quantitative-analysis.md §3.1-3.6（§3.4.1/§3.4.2 统计校正部分归并至文末附录），v0.11.2 起本节为单一事实源。

> **指标区分（防混淆）**：§3.1 四级表的波动率阈值（<3% / 3-5% / >5% / >8%）是**日波动率**口径；本节的突变评级规则使用**年化 HV_20d 变化幅度**——两者是不同指标，不可互相套用。四级状态判定以 §3.1 为权威，本节 HV 规则用于轨道B信号升级的中间判定。

#### 3.1B.1 波动率指标与可得性

| 波动率类型 | 定义 | 数据可得性 | 对信用分析的意义 |
|-----------|------|-----------|-----------------|
| **历史波动率(HV)** | 股价/收益率过去N日收益率的标准差（年化） | 上市公司可获取（免费行情） | 反映企业价值的不确定性 |
| **隐含波动率(IV)** | 从期权市场价格反推 | ❌ 不可获取——中国信用债/CDS期权市场不存在 | N/A |
| **已实现波动率(RV)** | 高频交易数据计算的日度波动率 | 仅高流动性股票可获取（分钟级行情付费） | 使用日度HV代替 |
| **特质波动率** | 剥离市场因子后的残差波动 | 可从免费数据回推测算 | 反映企业自身风险 |

**硬约束：** 非上市公司无股价数据，波动率分析完全不可用。这是轨道B在非上市企业上的核心局限之一。

#### 3.1B.2 历史波动率计算规范

```
基础参数：
├── 数据源：免费行情API / 财经网站（新浪财经、东方财富等）
├── 价格类型：收盘价（复权）
├── 收益率计算：ln(P_t / P_{t-1}) × 100%
├── 年化因子：√252（交易日数）
└── 计算窗口：20日 / 60日 / 120日（同时输出）

HV公式：
  HV = σ(r) × √252
  其中 σ(r) = 窗口期内日收益率的标准差

输出格式：
  HV_20d: 35.2%  （短期——反映最近一个月的不确定性）
  HV_60d: 28.7%  （中期——反映近一个季度的不确定性）
  HV_120d: 32.1% （长期——反映近半年的不确定性）
  HV_Trend: "上升" | "下降" | "稳定"（通过20日移动平均判断）
```

#### 3.1B.3 波动率分解框架（简化单因子）

```
Step 1: 获取行业指数/市场指数收益率
  市场代理：沪深300 (000300.SH)
  行业代理：光伏产业指数 (931151.CSI) / 中证行业指数

Step 2: 滚动回归（窗口=120交易日）
  R_i = α + β × R_m + ε
  其中 R_i = 个股日收益率，R_m = 指数日收益率，
       ε = 残差（特质收益），β = 系统性因子暴露

Step 3: 波动率分解
  总波动率(V_total) = β² × V_m + V_ε
  系统性占比 = β² × V_m / V_total × 100%
  特质占比 = V_ε / V_total × 100%

Step 4: 输出
  ├── 系统性波动占比 / 特质波动占比
  ├── 系统性波动趋势（与行业对比）
  └── 特质波动趋势（"上升——反映企业个性化风险增加"）
```

**局限性标注：** 简化单因子模型未考虑行业β的时变性；120日窗口期内假设β稳定——在波动率市中这个假设较弱；非上市公司此分析不可用。

#### 3.1B.4 波动率突变与预警信号

| 波动率模式 | 检测方法 | 信用含义 | 建议行动 |
|-----------|---------|---------|---------|
| **波动率尖峰** | HV > 历史均值 + 3σ | 突发信用事件 | 检查同期新闻/公告——可能是评级下调、诉讼、技术问题 |
| **波动率持续性上升** | HV_20d > HV_60d > HV_120d 持续5日 | 不确定性系统性增加 | 关注——领先利差走阔6-12周 |
| **波动率+利差双升** | 两者同时突破阈值 | 信用质量恶化确认 | 强烈信号——市场同时在两个维度上重新定价 |
| **低波动下突然尖峰** | 此前HV<均值·突然跃升至>均值+2σ | 风险被低估后暴露 | 最危险的信号——市场此前忽视了累积风险 |
| **波动率与基本面背离** | 基本面稳定但波动率飙升 | 市场存在框架未捕捉的担忧 | 分歧信号——需要排查隐性风险 |

**波动率突变评级规则（HV_20d变化幅度口径）：**

| HV_20日变化幅度 | 评级调整 | 说明 |
|----------------|---------|------|
| < 10% 且趋势稳定 | 无变化 | 正常波动 |
| 10-30% 上升 | 轨道B信号升级→关注 | 不确定性增加，需关注 |
| 30-50% 上升 | 轨道B信号升级→异常 | 显著变化，建议排查原因 |
| > 50% 上升 | 轨道B信号升级→危机 | 剧烈波动，可能触发交叉对撞分歧A |
| 20% 以上下降 | 无变化/降级 | 不确定性收窄——中性或正面信号 |

#### 3.1B.5 回溯验证结论（双良节能案例指针）

双良节能（600481）回溯验证（完整数据表已随 quantitative-analysis.md 归档，见 dev/engine/audits/quantitative-analysis.md §3.5 案例原始记录）的结论要点：

1. HV_20d在2025年10月开始上升，领先评级下调（2026-05，AAA→AA）约7个月
2. 2025年12月HV突破"均值+2σ"阈值，领先约5个月
3. 收益率波动率先于利差和评级反应——**波动率是领先信号**
4. 评级下调时波动率已在高位维持5个月——评级滞后被量化确认

**框架判决：** 波动率信号在评级下调前5个月已给出明确警示，验证了波动率分析在信用预警中的领先性。该信号的量化规则可直接编码为AI Agent的推理逻辑。

#### 3.1B.6 波动率分析的核心局限

| 局限 | 说明 | 影响程度 |
|------|------|---------|
| **非上市公司不可用** | 无股价/行情数据，波动率分析完全无法开展 | 高——约50%的发债主体是非上市公司 |
| **窗口期选择偏差** | 不同窗口期给出的信号可能矛盾 | 中——应同时输出多窗口，以趋势而非绝对值为准 |
| **市场噪声误报** | 波动率升高不一定代表信用恶化——可能是行业轮动、流动性冲击 | 中——必须配合利差+成交量交叉验证 |
| **历史波动率滞后于隐含波动率** | HV是对过去的统计，IV才是前瞻性的 | 中——但IV不可获取，只能用HV方向性近似 |
| **极端行情下相关性趋同** | 压力时期所有波动率同步上升，区分度下降 | 低——此时应切换到多因子分析 |

### 3.2 轨道B评分映射

| 市场状态 | 轨道B评分 | 含义 |
|---|---|---|
| 全部四级处于平静 | 8-10 | 市场对信用质量无担忧 |
| 1-2个维度进入关注 | 5-7 | 市场出现谨慎信号 |
| 1-2个维度进入异常 | 3-4 | 市场定价反映实质性风险 |
| 任何维度进入危机 | 0-2 | 市场定价反映违约预期 |

### 3.3 市场隐含信号与领先窗口

归并自 quantitative-analysis.md §7.4-7.7，v0.11.2 起本节为单一事实源。

市场隐含信号是从**非信用债资产的价格行为**中提取的信用线索——发行利率、股价、北向资金等。它们不直接来自信用利差，但在公开数据环境下是轨道B的重要补充。

#### 3.3.1 发行利率变化→市场重定价

新发债券的发行利率是市场对发行人信用的**最实时、最干净的定价信号**——因为它不受二级市场流动性干扰。

| 信号类型 | 检测规则 | 信用含义 |
|---------|---------|---------|
| **同企业新发行利率跳升** | 新发利率 > 上次发行 + 50bp（同期限） | 市场对发行人的信用评价恶化 |
| **发行利率 vs 市场估值** | 发行利率 > 中债估值 + 20bp | 一级市场比二级市场更悲观——关注 |
| **发行失败/取消** | 公告取消或延期 | 严重信号——市场不接受当前定价 |
| **发行利率跨越评级线** | 新发利率 > 低1-2档评级的市场均值 | 市场认为实际信用质量低于名义评级 |
| **同行业新发利率趋势** | 行业新发利率均值连续上升 | 行业整体在承受更高融资成本 |

**回溯验证结论（通威股份案例指针）：** 通威短融发行利率2025年持续下行（货币宽松环境），2026-01出现+13bp拐点、2026-04继续+30bp——该拐点无法被宏观利率解释（2026年初货币市场利率平稳），表明**信用溢价在独立上升**：即使AAA评级维持，市场已开始重新定价其信用风险。（完整发行序列已随 quantitative-analysis.md 归档，见 dev/engine/audits/quantitative-analysis.md §7.4 案例原始记录）

#### 3.3.2 股价持续下跌+波动率放大→领先债市

股票市场比债券市场对信用质量变化更敏感——原因：流动性更高、交易者类型更多元、信息传递更快。

```
信号组合：股价持续下跌 + 波动率放大
检测条件：
  1. 股价：过去60日累计跌幅 > 20%
  2. 波动率：HV_20d > HV_60d 且 HV_60d 处于历史80%分位数以上
  3. 成交量：日均成交量 > 历史均值（排除流动性枯竭导致的伪信号）
  4. 🟠 以上全部满足 → 信用预警信号

信号含义：
  ├── 股权市场已在"用脚投票"反映信用担忧
  ├── 债券市场通常滞后2-6周（对定向信息）或 6-12周（对系统性信息）
  └── 信号强度随条件满足的数量递增

交叉验证：
  ├── 检查同期是否有：评级行动 / 业绩预警 / 再融资事件
  ├── 行业内对比：同行业其他企业是否也在下跌 → 排除行业系统性下跌
  └── 基本面确认：轨道A是否支持"信用恶化"的判断
```

**回溯验证结论（华晨汽车案例指针）：** 2018-10-11宝马增持公告后，华晨中国（01114.HK）单日-24.54%、公告后1个月累计-35%、HV_20d从28%翻倍至65%；而债市2周内利差仅走阔约35bp——**债市反应滞后且平缓，股票市场领先了约8-12周**。

#### 3.3.3 北向资金/融资余额→机构态度

| 信号 | 数据源 | 可得性 | 对信用分析的指示 |
|------|-------|--------|-----------------|
| **北向资金（陆股通）持有量变化** | 港交所每日披露 | ✅ 免费 | 外资机构对股票的持续态度——间接反映对信用质量的看法 |
| **融资余额变化** | 交易所每日披露 | ✅ 免费 | 杠杆投资者的风险偏好——快速撤出可能预警 |
| **大宗交易折溢价** | 交易所披露 | ⚠️ 部分免费 | 大额交易方对公允价值的判断——但通常视为机构调仓 |
| **大股东质押比例变化** | 公司公告 | ✅ 公开 | 大股东资金链紧张——公司层面的关联风险 |

**北向资金信号提取与检测：**

```
1. 获取目标企业（如上市）陆股通持仓数据（日度）
2. 分解持仓市值变动为：价格效应 + 实际买卖
   实际买卖 = 持仓市值变动 - (持仓量 × 股价变动)
3. 检测：
   ├── 连续5日净卖出（实际买卖为负）→ 🟡 外资在减持
   ├── 周度持仓占比下降 > 10% → 🟠 外资态度明显转淡
   └── 北向持仓占比创3个月新低 → 🔴 机构信心不足

局限标注：
  ├── 仅适用于沪港通/深港通标的——非所有发债企业都有北向数据
  ├── 北向买卖可能有非信用原因（组合再平衡、行业轮动、汇率对冲）
  └── 北向资金在中国A股占比约3-5%——信号强度有限
```

#### 3.3.4 信号综合评估表

| 市场隐含信号 | 数据源 | 领先债市窗口 | 可靠性 | 可用性 |
|------------|-------|------------|-------|-------|
| 转股溢价率（转股价值口径） | 可转债公开行情 | 0-4周 | 中 | ✅ |
| 发行利率变化（一级市场） | 发行公告/中国货币网 | 0-2周（即时） | 高 | ✅ |
| 股价累计跌幅+波动率放大 | 免费行情API | 2-12周 | 中高 | ✅（上市公司） |
| 北向资金持续减持 | 港交所 | 4-12周 | 中 | ⚠️（仅沪港通标的） |
| 融资余额撤出 | 交易所 | 1-4周 | 中 | ⚠️（仅两融标的） |
| 大股东质押率上升 | 公司公告 | 8-24周 | 中 | ✅ |

## 四、交叉对撞矩阵

### 4.1 四象限对撞

```
                 │ 轨道B：平静          │  轨道B：异常/危机
                 │ (评分 8-10)          │   (评分 0-4)
─────────────────┼──────────────────────┼─────────────────────
轨道A：良好      │  共识                │  分歧A
评分 6-10        │  互相强化确认        │  市场在恐慌什么？
                 │  评级可信度高        │  是否过激？还是框架遗漏？
─────────────────┼──────────────────────┼─────────────────────
轨道A：较差      │  分歧B               │  共识
评分 0-5         │  市场在忽视什么？    │  互相验证确认
                 │  是框架太激进？      │  风险已全面定价
                 │  还是有隐藏风险？    │  评级可信度高
```

### 4.2 分歧处理规则

| 分歧类型 | 优先相信 | 理由 |
|---|---|---|
| **分歧A**（A好+B差） | **轨道A** | 市场可能过度反应；需检查是否有框架未捕捉的外部负面因素 |
| **分歧B**（A差+B好） | **轨道A** | 外部评级滞后是已知问题（已验证滞后17+个月）；市场可能被叙事蒙蔽 |

**核心原则：当两轨分歧时，优先相信轨道A（可审计的公开财务事实）而非轨道B（外部评级和市场价格）。**

### 4.3 偏离度评分（建议新增）

偏离度评分（0-10分）：衡量轨道A与轨道B的一致性程度。

| 偏离度 | 含义 | 操作建议 |
|---|---|---|
| 0-3 | 高度一致 | 自动输出，无需人工介入 |
| 4-6 | 中度偏离 | 自动触发复核提醒 |
| 7-10 | 严重偏离 | 必须人工分析师介入 |

## 五、现金流深度分析

> **权威源引用**：FCF分析的完整计算规格（含分级标准、庞氏检测、营运资金联动）见[财务深度分析报告](financial-deep-dive.md) §D。本节为双轨架构中的定位摘要。

### 5.1 核心公式

自由现金流（FCF）是衡量企业真实造血能力的核心指标，在L4财务层评分中作为验证性输入：

```
FCF = 经营活动现金流净额 - 资本支出
FCF/收入 = FCF / 营业收入
FCF/利息 = FCF / 利息支出
```

数据来源：年报现金流量表（经营活动现金流净额、购建固定资产/无形资产/其他长期资产支付的现金、分配股利/利润/偿付利息支付的现金）。

### 5.2 FCF生成能力分级

| FCF/收入 | FCF/利息 | 判定 | 含义 |
|---|---|---|---|
| >5% | >3x | 🟢 造血能力强 | 经营现金流充裕，可同时覆盖投资和偿债，信用风险低 |
| 0-5% | 1-3x | 🟡 维持性经营 | 仅能维持现有运营和基本偿债，扩张依赖外部融资 |
| <0 | <1x | 🟠 依赖融资输血 | 经营现金流不足，需持续融资支持——短期可承受，长期不可持续 |
| 任何值 | <0（持续>2年） | 🔴 庞氏融资嫌疑 | FCF持续为负且无法覆盖利息支出——紫光集团（2017-2019连续3年）、华晨集团（2018-2020）的共性特征 |

### 5.3 与评级映射的衔接

FCF分析结果不直接改变轨道A综合评分，但作为L4财务层的**验证性修正输入**：

- **FCF/收入 > 5% 且 FCF/利息 > 3x**：L4评分上限可在常规上限基础上+1分（信用质量强化确认）
- **FCF/收入 < 0 且 FCF/利息 < 1x**：L4评分上限锁定为4分（满分10分），即财务层无论其他指标多好，最高评分为4
- **FCF/利息持续<0超过2年**：触发"庞氏融资嫌疑"风险警告，综合评级上限锁定为B（无论其他层评分多高）

### 5.4 与营运资金分析的联动

FCF质量需结合营运资金效率（DSO/DIO/DPO/CCC）交叉验证：

| FCF特征 | 营运资金特征 | 联合判定 |
|---|---|---|
| FCF为正 | CCC正常或优化 | 真实造血，FCF可信 |
| FCF为正 | CCC恶化（DSO上升/DIO堆积） | FCF质量存疑，利润可能被营运资金占用侵蚀 |
| FCF为负 | CCC自然恶化 | 经营基本面恶化，需关注现金流跑道 |
| FCF为负 | CCC改善（靠压应付账款） | 短期粉饰，不可持续 |

## 七、EL预期损失整合

**【评级修订 v0.4.0】** 新增PD评级与LGD框架的整合层，实现EL（Expected Loss，预期损失）的量化估算。

### 7.1 核心公式

```
EL = PD × LGD × EAD

其中：
  PD  = 从PD评级映射的年化违约概率（取区间中值作为点估计）
  LGD = 从LGD五级分类映射的违约损失率
  EAD = 默认按本金 + 应计利息计算（简化处理，不考虑信用转换系数CCF）
```

### 7.2 PD到违约概率的映射

PD评级映射为年化违约概率区间，参考Moody's全球历史违约率统计数据：

| PD评级 | 对应的年化PD区间 |
|---|---|
| AAA | < 0.01% |
| AA+/AA/AA- | 0.01% - 0.05% |
| A+/A/A- | 0.05% - 0.15% |
| BBB+/BBB/BBB- | 0.15% - 0.50% |
| BB+/BB/BB- | 0.50% - 2.0% |
| B+/B/B- | 2.0% - 8.0% |
| CCC | 8.0% - 30% |
| D | > 30% |

**诚实标注：** 上述PD区间基于Moody's《Corporate Default and Recovery Rates, 1920-2023》全球统计数据。中国信用债市场违约样本不足200个（截至2025年末），未经中国市场校准。这些PD区间仅供排序参考，不可用于监管资本计算。

### 7.3 LGD损失率映射

LGD等级定义（五级分类、损失率/回收率区间、典型场景）见[LGD与回收率分析框架](lgd-recovery-framework.md) §二——权威定义，本处不复制表体。

### 7.4 输出示例（通用模板）

```
评级: BB+
年化PD: 0.5%-2.0%（中值1.0%）
LGD: LGD2（20-40%，优质抵押覆盖）
EAD: 本金1亿元 + 应计利息200万元 = 1.02亿元
EL: 1.0% × 30% × 1.02亿 = 30.6万元
    （即预期损失率为0.30% × 本金）
```

### 7.5 实际案例：隆基绿能EL计算

以下用隆基绿能（分析日期：2026-07）展示完整的PD × LGD × EAD计算链。

**第一步：从评级映射PD**

隆基绿能轨道A综合评分7.50 → 评级映射为A+（7.5-7.9区间，中低风险）

| PD评级 | 对应年化PD区间 | 使用中值（点估计） |
|--------|---------------|-----------------|
| A+ | 0.05% - 0.15% | **0.10%** |

数据来源：7.2节PD映射表，基于Moody's全球违约率统计。

**第二步：评估LGD**

隆基绿能存续债券为无担保普通信用债，按LGD框架：

| LGD因子 | 评估 | 说明 |
|---------|------|------|
| 债项优先级 | 无担保（Senior Unsecured） | 无特定抵押物覆盖 |
| 行业回收率基准 | 光伏设备制造 | 重资产行业，设备有一定残值但技术迭代快 |
| 抵押物/担保 | 无 | 纯信用债 |
| LGD评级 | **LGD3** | 对应损失率区间40%-60%，使用中值50% |

数据来源：[LGD与回收率分析框架](lgd-recovery-framework.md)第二节LGD五级分类体系。

**第三步：确定EAD**

以隆基绿能2024年发行的某期中票为例：

| EAD构成 | 数值 | 说明 |
|---------|------|------|
| 本金 | 10亿元 | 发行面值 |
| 应计利息（3个月） | 1,350万元 | 票面利率约5.4% |
| **EAD合计** | **10.135亿元** | 简化计算，不考虑CCF |

**第四步：计算EL**

```
EL = PD × LGD × EAD

PD  = 0.10%（A+评级中值）
LGD = 50%（LGD3中值，无担保信用债）
EAD = 10.135亿元

EL = 0.10% × 50% × 10.135亿
   = 0.0005 × 10.135亿
   = **50.7万元**

即预期损失率为0.05% × 本金（0.10% PD × 50% LGD）
```

**第五步：对比解读——评级 vs EL**

| 分析工具 | 结论 | 精确度 |
|---------|------|--------|
| **仅看评级（A+）** | "中低风险，整体信用质量良好" | 定性描述，无法量化损失 |
| **看EL（0.05% × 本金）** | "预期损失约本金的0.05%，即每亿元敞口预期损失约5万元" | **量化精确，跨债项可比** |

**为什么EL比单纯评级更精确？**

1. **区分同一评级内的差异**：两家A+企业，一家有优质抵押（LGD2）一家无担保（LGD3），EL相差约1倍。评级本身无法反映这一差异。
2. **将PD和LGD的变动转化为一致标尺**：评级是从"亏损概率"角度排序，EL是从"预期亏损金额"角度排序。对投资组合管理者而言，后者更具可操作性。
3. **EL可直接用于组合层面**：将每个债项的EL加总，得到组合层面的预期损失，用于拨备计提和风险预算分配。

**重要限制说明**（同7.5节）：

| 限制 | 对隆基案例的具体影响 |
|------|---------------------|
| PD区间未经中国市场校准 | 中国光伏企业实际违约率可能与Moody's全球基准有差异 |
| LGD为简化估算 | 隆基绿能若发生违约，实际回收率可能偏离40%-60%区间 |
| EL是排序工具 | 50.7万元为排序参考值，不是精确预测值

### 7.6 重要限制说明

1. **PD映射未经中国市场校准：** 上述PD区间引用Moody's全球数据。中国信用债违约样本不足200个，实际违约率可能因市场结构（国企主导）、监管环境（地方政府协调）和司法实践（破产重整清偿率差异）与全球基准显著不同。
2. **LGD为简化估算：** LGD区间来自框架设定值，并非基于中国市场的历史回收率统计。详见[lgd-recovery-framework.md](lgd-recovery-framework.md)的诚实性声明。
3. **EL是排序工具而非计量工具：** 本框架的EL估算用于比较不同债项的信用风险排序，不能替代Basel II/III框架下的监管资本计量。
4. **EAD简化处理：** 不考虑表外风险暴露的信用转换系数，因为引擎当前分析对象为信用债（本金+利息敞口明确）。

### 7.7 中国市场参考

#### 7.7.1 中国信用债市场违约概况（2014-2026）

中国信用债市场违约历史短、样本少，但趋势清晰：

| 年份 | 违约主体数量 | 涉及债券规模（亿元） | 标志性事件 |
|---|---|---|---|
| 2014 | 1 | 10 | 超日债违约——中国公募债首例违约 |
| 2015 | 6 | 120 | 天威、二重——国企违约开端 |
| 2016 | 26 | 400 | 东特钢、中铁物资——央企/国企连环违约 |
| 2017 | 9 | 110 | 违约回落（供给侧改革改善企业盈利） |
| 2018 | 34 | 860 | 民企违约潮（去杠杆+资管新规） |
| 2019 | 51 | 1250 | 永煤违约前兆、方正破产重整 |
| 2020 | 39 | 1100 | 永煤AAA违约（2020.11）——国企信仰彻底打破 |
| 2021 | 31 | 1130 | 华夏幸福、恒大——房地产行业违约潮开启 |
| 2022 | 40 | 1690 | 房地产违约高峰（融创、世茂、龙光等） |
| 2023 | 35 | 1600 | 房地产延伸违约+城投非标违约增加 |
| 2024 | 28 | 1300 | 房地产违约边际缓和，城投公开债零违约 |
| 2025 | 22 | 900 | 违约量下降，信用分化加剧 |

**汇总（2014-2025）：** 累计违约主体约300个（含重复违约），涉及债券规模约1.2万亿元。但其中**真正意义上的公开债券违约样本不足200个**（大部分为已暴露主体的后续违约或非公开违约）。

> **统计意义声明：** 中国信用债市场的有效违约样本远低于Moody's全球违约数据库（1920-2023年超过5000个样本）。以下所有基于中国数据的PD估算均为**方向性参考**，统计置信区间极宽，不可用于监管资本计算或精确风险定价。

#### 7.7.2 中国市场PD参考估算

基于2014-2025年中国信用债市场的实际违约数据，对各评级区间的年化违约概率进行粗略估算：

| 初始外部评级 | 年化违约率（中国市场估算） | 统计基础 | 说明 |
|---|---|---|---|
| AAA（央企/大国企） | < 0.05% | 样本约2000主体年，仅永煤1例 | 国企AAA违约率极低，但不为零 |
| AAA（民企） | 样本极少 | — | 民企极少获得AAA，无统计意义 |
| AA+/AA/AA-（地方国企） | 0.1% - 0.5% | 样本约5000主体年 | 2018年后分化加剧，弱资质AA违约上升 |
| AA+/AA/AA-（民企） | 0.5% - 2.0% | 样本约1500主体年 | 民企AA违约率显著高于国企同评级 |
| A+/A（民企/弱国企） | 2.0% - 4.0% | 样本约800主体年 | 2018年后大量A级民企违约 |
| A-及以下 | 4.0% - 10%+ | 样本有限 | 评级越低样本越少，统计噪声大 |
| 无评级（非公开发债主体） | 依赖替代方法 | — | 须通过马赛克引擎替代数据评估 |

**来源说明：** 上表基于以下公开来源交叉验证：中债资信《中国债券市场违约及信用风险研究报告》（历年）、联合资信《中国信用债市场违约率统计年报》（历年）、Wind/DM终端违约数据统计。

> **误差范围：** 上述估算的统计误差可能达到±50%-100%（特别是低评级区间），仅供内部排序参考。

#### 7.7.3 评级迁移矩阵参考

中国评级机构（中诚信国际、联合资信、中债资信等）定期发布信用评级迁移矩阵。迁移概率矩阵的权威版本见 [outlook-monitoring-framework.md](outlook-monitoring-framework.md) §5.1（1 年期迁移概率矩阵，`src/outlook_engine.py` 运行时解析源），本处不复制表体。

**迁移矩阵反映的中国市场特征：**

1. **评级上调极少**——上调比例低（AAA 0%、AA 级仅 3-5%），远低于国际水平（5-10%），反映评级分布整体向上偏移后缺乏上调空间。
2. **AAA级几乎不迁移**（维持率95%+），评级调整几乎不反映违约风险变化。
3. **AA是信用分水岭**——AA级以上违约率极低，AA-及以下违约率激增。这与国际市场上BBB为投资级分水岭的格局完全不同。
4. **2018年后矩阵右偏恶化**——去杠杆后各评级下调迁移率显著上升。

#### 7.7.4 SOE vs 非SOE违约率差异

中国信用债市场最显著的区分特征是国企与民企的违约率鸿沟：

| 比较维度 | 中央国企 | 地方国企 | 民营企业 |
|---|---|---|---|
| 2014-2025累计违约主体 | 10-15个 | 30-50个 | 200+个 |
| 占全部违约比例 | < 5% | 15-20% | 75-80% |
| AAA主体历史违约率 | ~0.02%（仅永煤1例） | ~0.1% | 样本不足 |
| 同评级违约率比较（AA） | 基准（最低） | 央企的2-3x | 央企的10-20x |
| 违约后回收率 | 较高（政府协调） | 中（地方政府主导） | 低（市场化处置为主） |
| 首次刚兑打破时间 | 2020年（永煤） | 2015年（天威） | 2014年（超日） |

**核心结论：**

1. **SOE违约风险不是零但显著低于同评级非SOE。** 永煤违约（2020年11月）证明了"国企不违约"信仰的终结，但国企违约率仍远低于相同评级的民企。

2. **同评级内部SOE/非SOE违约率差异超过1-2个评级档位。** 建议在PD映射中对SOE给予**隐性+1子级**的校准偏移——即一个AA级地方国企的PD参考区间相当于同评级民企的AA-档位。

3. **"逃废债"（恶意违约）是非SOE特有的风险。** 民营企业通过资产转移、破产重整逃避债务的案例显著多于国有企业（详见[治理与欺诈风险](governance-fraud-risk.md)）。

4. **地方政府在国企违约中的角色是关键变量。** 有协调价值的国企违约后政府介入可能性高、回收率也更高；无协调价值的国企更接近市场化处置。

#### 7.7.5 中国信用债市场特有因素

以下因素造成中国市场的PD特征与Moody's全球基准存在系统性差异：

| 因素 | 对PD影响方向 | 影响机制 | 影响程度 |
|---|---|---|---|
| **政府支持隐含上调** | 降低违约率（对国企） | 地方政府/中央政府在部分国企面临违约风险时介入协调（流动性支持/续贷协调/并购重组） | 中-高（对地方国企PD降幅可达50%） |
| **刚兑打破历史短** | 结构不稳定 | 中国公募债2014年才首例违约，市场运行不到12年，违约率仍在上升通道，尚未进入稳态 | 中（实际违约率可能仍低于长期均衡水平） |
| **"逃废债"风险** | 推高违约率（民营） | 部分企业有能力偿债但选择违约（资产转移/破产逃废债），还款意愿风险远高于国际市场 | 中-高（对民企额外提高PD 50-100%） |
| **评级虚高/区分度不足** | 同评级实际违约率离散 | 中国评级AAA+AA占比>60%（国际市场<20%），同一评级内部信用质量差异远大于国际市场 | 高（同评级违约率离差可能是国际3-5倍） |
| **增信措施效力不确定** | 视增信类型而定 | 担保/抵押法律效力存在执行风险（政府协调可能绕过担保条款；抵押物处置流程复杂） | 中（增信效力约为国际标准60-80%） |
| **区域风险分化** | 推高部分区域违约率 | 经济弱省信用风险无法通过个体分析单独评估，需叠加区域分析（详见[城投双轨框架](lgfv-framework.md)） | 中（区域分化导致PD差异3-5倍） |
| **系统性冲击事件** | 短期全市场PD同步上升 | 如永煤违约后发行冻结、2022年理财赎回潮——全市场利差飙升，所有评级PD同步上升 | 短期极高但非稳态——不作为正常时期PD调整基准 |

#### 7.7.6 中国市场校准总结

中国市场PD映射的**方向性校准建议**（非精确调整——精确需要超过2000个有效违约样本）：

| 调整维度 | 建议 | 操作提示 |
|---|---|---|
| **央企AAA** | 维持Moody's全球基准（< 0.01%） | 极少数样本支持 |
| **地方国企AA+至AA-** | 在Moody's基准上降低30-50% | 政府协调效应显著 |
| **国企A+及以下** | 接近Moody's基准 | 政府支持效力随评级下降递减 |
| **民企AAA** | 样本不足，参考AA+级Moody's基准 | 慎用AAA——中国民企AAA实际信用质量约当国际AA |
| **民企AA+至AA-** | 在Moody's基准上提高50-100% | 逃废债+高波动性 |
| **民企A+及以下** | 在Moody's基准上提高100-200% | 违约风险极高，谨慎投资 |
| **弱资质城投（绑定政府）** | 不直接适用PD映射——参考[城投双轨框架](lgfv-framework.md) | 城投信用由政府信用+平台质量双轨决定 |

> **核心诚实标注：** 上述校准建议基于不到200个有效违约样本的次级分析，统计显著性和普适性有限。建议用户在实际应用中将中国校准的PD区间视为方向参考而非精确概率。当需要精确PD用于定价时，优先采信Moody's全球基准（样本充分、统计稳健），中国市场校准仅作为"上/下方向调整"参考。

## 九、风险缓释建议框架

> **来源**：[风险管理标准审计报告](audits/risk-management-standards-audit.md) （G1 — 风险缓释建议的缺失）
> **说明**：引擎现有输出止步于"风险识别"和"风险评估"，缺少"应该怎么办"的具体指引。本框架提供的不是投资建议（"该买还是该卖"），而是在用户已决定降低风险的前提下，帮助选择最合适的缓释路径。

### 9.1 设计原则

1. **不是投资建议**：本框架不回答"该买还是该卖"，只回答"如果要降低风险，有哪些可选路径"
2. **场景匹配**：每种缓释路径标注适用场景和成本，不搞"一刀切"
3. **诚实标注**：某些风险（如系统性风险）无法通过单一组合调整来缓释——必须如实指出
4. **与现有分析衔接**：缓释建议基于引擎已完成的信用分析结论（评级、场景压力测试、集中度分析等），不重复分析

### 9.2 缓释路径菜单

| # | 缓释路径 | 适用场景 | 有效性 | 成本/代价 | 实施难度 |
|---|---|---|---|---|---|
| 1 | **缩短久期** | 信用质量不确定，利率上行风险 | ⭐⭐⭐⭐ 高 | 可能损失Carry收益（短券收益率低） | 容易——卖出长券换短券 |
| 2 | **增加担保/增信要求** | 单主体信用质量偏弱但仍有缓释空间 | ⭐⭐⭐⭐ 高 | 影响融资成本（发行人可能要求补偿） | 中——需重新谈判条款 |
| 3 | **分散到不同区域** | 区域集中度过高（单一省份敞口>20%） | ⭐⭐⭐ 中高 | 交易成本+新区域研究成本 | 中——需寻找新投资标的 |
| 4 | **分散到不同行业** | 行业集中度过高（单一行业敞口>30%） | ⭐⭐⭐ 中高 | 跨行业研究门槛 | 中——需理解新行业逻辑 |
| 5 | **购买CDS/CRMW** | 个券信用风险暴露敞口较大，但不想直接卖出 | ⭐⭐⭐ 中 | 保费成本（可参考信用利差定价） | 中——市场深度有限，需交易对手 |
| 6 | **降低单一敞口** | 单主体集中度过高（>10%组合） | ⭐⭐⭐⭐⭐ 最高 | 交易佣金+流动性冲击（如持有比例高） | 容易——在二级市场分批减持 |
| 7 | **增加质押式回购能力** | 流动性储备不足，需要提升流动性 | ⭐⭐ 中 | 抵押品占用，杠杆率上升 | 中——需开户/授信 |
| 8 | **增加利率对冲** | 久期敞口大，利率上行风险 | ⭐⭐ 中 | 对冲成本（期货/IRS） | 中——需衍生品交易能力 |
| 9 | **增加条款保护** | 新投资或存续券可变更条款 | ⭐⭐⭐ 中高 | 可能降低发行利差（保护越强票息越低） | 中等——仅适用一级市场或持有人会议 |
| 10 | **清仓/退出** | 触发一票否决条件或评分<3 | ⭐⭐⭐⭐⭐ 最高 | 交易成本+机会成本+可能影响市场信誉 | 容易（市场流动性好时） |

### 9.3 缓释路径推荐规则

基于引擎输出结果自动生成缓释建议：

| 引擎发现 | 推荐缓释路径 | 优先级排序 |
|---|---|---|
| **A. 单主体信用质量恶化**（评级降至B以下） | ① 降低单一敞口 ② 缩短久期 ③ 购买CRMW ④ 增加担保要求 | ①>③>②>④ |
| **B. 行业集中度过高**（单一行业>30%） | ① 分散到不同行业 ② 对行业高风险主体降低敞口 ③ 购买行业指数CDS（如有） | ①>②>③ |
| **C. 区域集中度过高**（高风险区域>10%） | ① 分散到不同区域 ② 降低高风险区域敞口 ③ 关注区域化债进展 | ①>②>③ |
| **D. 伪高评级占比过高**（>15%） | ① 逐只排查伪高评级券 ② 降低评分<5的券 ③ 要求增加担保 | ①>②>③ |
| **E. 流动性风险突出**（现金跑道<6个月） | ① 缩短久期 ② 增加质押能力 ③ 保持现金储备 | ②>①>③ |
| **F. Bear场景不通过**（利息覆盖<1.5x） | ① 大幅降低敞口 ② 购买CDS ③ 要求追加抵押品 | ①>③>② |
| **G. Severe场景不通过**（利息覆盖<1.0x） | ① 清仓退出 ② 或要求全额担保 ③ 缩短至超短久期 | ①（如可退出）>③（如不可退出） |
| **H. 治理风险高**（🔴治理信号触发） | ① 降低敞口至0.5%以下 ② 要求交叉违约条款 ③ 加速到期安排 | ①>②>③ |
| **I. 逃废债嫌疑**（还款意愿评分<-50） | ① 仅推荐清仓退出 ② 无可接受的替代缓释路径 | ①（必选） |

### 9.5 重要限制与诚实标注

**必须标注的缓释局限性**：

| 局限性 | 说明 |
|---|---|
| **系统性风险无法通过单一工具缓释** | 宏观衰退、流动性危机、监管政策急转——这些风险无法通过调整个券暴露来化解，只能降低整体风险预算或使用宏观对冲工具 |
| **CDS/CRMW市场深度有限** | 中国信用衍生品市场尚处发展早期，大多数个券没有对应的CDS或CRMW——对"购买保护"路径需要实际确认市场可得性 |
| **组合调整本身有成本** | 调仓需考虑交易成本（佣金+冲击成本）+ 税务成本 + 机会成本（卖出后错过可能的价格恢复） |
| **流动性约束** | 在市场压力时期，大量减仓可能导致更大的价格损失——"减仓"路径在危机中的实际效果可能远低于模型估算 |
| **缺失数据影响缓释效果判断** | 如果引擎分析本身的数据完备性偏低，缓释建议的置信度也会相应降低 |
| **委托代理问题** | 不同身份（基金经理 vs 信贷审批 vs 交易员）对同一缓释路径的成本承受力不同——M1基金经理对降低收益率的容忍度低于M0信贷审批 |

### 9.6 与交叉对撞矩阵的衔接

缓释建议的输出强度（建议力度）应与交叉对撞分歧度联动：

| 交叉对撞状态 | 缓释建议力度 | 说明 |
|---|---|---|
| **共识（A好+B好 或 A差+B差）** | 常规建议 | 信心充分，缓释建议按标准模板输出 |
| **分歧（A好+B差 或 A差+B好）** | 增强建议+方向性提示 | 存在不确定性→建议实施"不可逆的缓释路径"（如降低敞口）而非"可逆的缓释路径"（如缩短久期） |
| **数据不足** | 保守建议 | 缺少关键数据→缓释路径优先选择"信息不敏感"方案（如增加担保） |

#### 附录.1.1 因子分解框架

在公开数据约束下，使用**简化线性因子模型**分解企业信用利差的驱动因素：

```
目标变量：企业YTM利差（周度数据）
模型结构：
  Spread_i(t) = α_i + β_macro × F_macro(t) + β_ind × F_ind(t)
                + β_region × F_region(t) + ε_i(t)

  其中：
  ├── F_macro(t) = 宏观因子（利率水平/期限利差/信用利差指数）
  ├── F_ind(t)   = 行业因子（行业利差均值/行业指数收益率）
  ├── F_region(t)= 区域因子（区域利差均值——仅国企/城投适用）
  ├── α_i        = 特质alpha——企业自身信用质量的定价
  ├── β_*        = 各因子的暴露系数
  └── ε_i(t)     = 残差——未被因子解释的部分（模型误差+特质冲击）
```

#### 附录.1.2 简化单因子回归（公开数据约束下的可行方案）

由于中国企业债数据稀疏（尤其是非活跃券），多因子面板数据的可行性较低。以下为在**有限数据约束下**的可行简化方案：

| 因子 | 代理变量 | 数据源 | 适用性 |
|------|---------|-------|--------|
| **宏观利率** | 10年期国债收益率（月均） | 央行/公开市场数据 | 通用 |
| **宏观信用** | AAA企业债收益率曲线水平 | 中债登免费披露（月度） | 通用（但中债估值曲线精度较低） |
| **行业β** | 行业利差中位数变化 | 行业样本企业等权平均 | 需要≥3家样本企业 |
| **区域β** | 区域国企利差均值（如适用） | 区域样本企业等权平均 | 仅国企/城投——民营企业无区域β |
| **流动性** | 换手率（日均成交量/存量规模） | 交易所公开数据 | 流动性较低的券数据稀疏 |
| **特质α** | 残差项——滚动6个月回归的α | 模型内生 | 需要足够多的周度观测值（≥24周） |

**回归技术规范：**

```
回归类型：滚动OLS（窗口=24周，约6个月）
频率：周度
最小观测值：12周（不足则不输出因子分解）
约束：当样本企业<3家时，不计算行业β

输出格式：
  ├── R²：0.65（宏观+行业因子解释了65%的利差变动）
  ├── β_macro：0.42（利差对宏观利率的敏感度）
  ├── β_ind：0.38（行业利差每扩大10bp，个券利差扩大3.8bp）
  ├── α：+25bp（特质alpha为正——市场对该企业额外要求25bp溢价）
  └── 残差标准差：18bp（未被解释的部分——作为不确定性度量）

模型诊断：
  ├── Durbin-Watson统计量：1.85（无显著自相关）
  ├── VIF：< 3（无多重共线性）
  └── 残差正态性检验：p > 0.05（通过）
```

#### 附录.1.3 因子暴露的时变特征

因子暴露不是静态的——在市场环境变化或企业基本面变化时，因子β会漂移。检测规则如下：

| 信号 | 检测方法 | 含义 |
|------|---------|------|
| **β_macro上升** | 24周滚动β + 趋势回归 | 企业定价越来越受宏观驱动——信用质量向宏观敏感型漂移 |
| **β_ind下降** | 同上 | 市场不再以行业标签定价——个性化风险凸显 |
| **α从负转正** | α窗口突破±2σ | 市场开始对企业额外要求溢价——信用认知恶化 |
| **残差标准差扩大** | 滚动24周残差σ趋势上升 | 模型解释力下降——存在框架未捕捉的因子（隐性风险） |
| **R²急剧下降** | 周度R²从>0.6跌至<0.3 | 定价逻辑发生了结构性变化——因子模型需要重置 |

**规则应用：** 当检测到时变信号时，AI Agent应输出以下格式：

```
因子模型稳定性预警：
├── 检测到：β_macro在近12周从0.35上升至0.52（+49%）
├── 含义：企业定价从"行业驱动"转向"宏观驱动"
├── 可能原因：行业β正在失效——市场不再将企业当作"行业一员"定价
├── 建议：检查是否有企业个性化风险（财报恶化/治理问题/评级可能下调）
└── 置信度：中（24周窗口较短，时变检测可能有滞后）
```

```
利差均值 95% Bootstrap置信区间
├── 方法：非参数Bootstrap，重抽样1000次
├── 计算步骤：
```

#### 附录.2.2 多重假设检验校正（FDR，Benjamini-Hochberg）

**问题背景：** 同时监控N个主体×K种检测规则 = 大量并行假设检验，假阳性率随检验次数增加而膨胀。例如，同时监控100只债券的3种异常类型 = 300个并行检验，即使所有债券都正常，也会产生约15个假阳性信号（300×0.05）。

```
FDR校正规范（Benjamini-Hochberg程序）：
├── 设定FDR控制水平：q = 0.05（即允许5%的显著信号为假阳性）
├── 适用场景：
│   ├── 利差异常检测：同时检测N只债券的M种异常类型
│   ├── 波动率异常检测：同时检测N只股票的K种波动率模式
│   └── 任意涉及多重比较的场景
├── BH程序步骤：
│   1. 对所有m个并行检验的p值排序：p₁ ≤ p₂ ≤ ... ≤ pₘ
│   2. 找到最大的k，使得 pₖ ≤ (k/m) × q
│   3. 拒绝H₀对应的前k个检验 → 这些是"经FDR校正后显著"的信号
│   4. 其余m-k个检验虽原始p<0.05但经校正后不显著 → 标注"校正后不显著"
├── 输出规范：
│   ├── "今日触发预警数：15个"
│   ├── "经FDR校正后的显著信号数：8个"
│   ├── "未校正的原始信号数：15个"
│   └── "假阳性风险提示：今天触发的15个预警中，统计上约0-7个可能是假阳性"
└── 标注规则：
    ├── 校正后仍显著的信号 → 标注 "✅ FDR校正后显著"
    ├── 校正后不显著的信号 → 标注 "⚠️ 原始p<0.05但FDR校正后不显著"
    └── 全局标注："FDR校正：Benjamini-Hochberg程序，q=0.05"
```

#### 附录.2.3 波动率统计量的置信区间（卡方分布）

```
HV的95%置信区间公式（假设收益率近似正态分布）：
  [(n-1) × HV² / χ²₀.₀₂₅(n-1),  (n-1) × HV² / χ²₀.₉₇₅(n-1)]

其中：
├── n = 窗口期内的观测值数量（如20日窗口n=20）
├── HV = 历史波动率（年化）
├── χ²₀.₀₂₅(n-1) = 自由度为n-1的卡方分布2.5%分位数
├── χ²₀.₉₇₅(n-1) = 自由度为n-1的卡方分布97.5%分位数
└── 自由度说明：收益率均值为估计值，消耗1个自由度

计算示例（n=20, HV=35.2%）：
  χ²₀.₀₂₅(19) = 8.907
  χ²₀.₉₇₅(19) = 32.852
  CI = [19 × 0.352² / 32.852,  19 × 0.352² / 8.907]
     = [19 × 0.1239 / 32.852,  19 × 0.1239 / 8.907]
     = [0.0716, 0.2643]
     = [26.8%, 51.4%]（年化波动率）

输出："HV_20d: 35.2% [95% CI: 26.8%–51.4%]"
```

**波动率突变检测规则修订：**

```
旧规则：HV > 历史均值 + 3σ → 波动率尖峰
新规则：当前HV > 滚动窗口HV的95%置信区间上界 → 标记为波动率突变
        → 标注："当前HV = XX%，超出滚动窗口HV的95% CI上界（YY%）"

旧规则：HV_20d > HV_60d > HV_120d 持续5日 → 波动率持续性上升
新规则：HV_20d > HV_60d > HV_120d 且 HV_20d超出HV_60d的95% CI上界
        → 确认趋势具有统计显著性

旧规则：低波动下突然尖峰（此前HV<均值·突然跃升至>均值+2σ）
新规则：此前HV在95% CI内·突然跃升至超出95% CI上界
        → 最危险信号——风险被低估后暴露
```

**波动率FDR校正：** 与附录.2.2共用同一框架——并行检验来源为N只股票×3种波动率模式（尖峰/持续性上升/双升），3种波动率窗口（20日/60日/120日）可选择性合并；BH程序、输出规范与标注规则同附录.2.2（q=0.05）。

#### 附录.2.4 因子回归的置信区间（Newey-West稳健标准误）

```
所有β系数的输出格式（替代不带置信区间的点估计）：
  β_macro：0.42  [95% CI: 0.28–0.56]  ✅ p=0.003（显著）
  β_ind  ：0.38  [95% CI: 0.22–0.54]  ✅ p=0.012（显著）
  α      ：+25bp [95% CI: -8bp–+58bp] ❌ p=0.124（不显著）

计算规范：
├── 标准误类型：Newey-West异方差自相关一致标准误（HAC）
├── 滞后截断参数：按 Newey-West(1994) 自动选择，或取 floor(4×(T/100)^(2/9))
├── 置信区间：β̂ ± t₀.₀₂₅(df) × SE_HAC
└── 显著性标注：
    ├── p<0.05 → 标注 "✅ p=XX（显著）"
    └── p≥0.05 → 标注 "❌ p=XX（不显著）"
```

**回归R²的置信区间（通过F分布转换）：**

```
├── 方法：R² → F统计量 → F分布置信区间 → 回转为R²置信区间
├── 公式：F = (R²/k) / ((1-R²)/(n-k-1))
├── 输出："R²: 0.65 [95% CI: 0.52–0.76]"
└── 前提：n≥30，且残差近似正态（否则使用Bootstrap替代）
```

#### 附录.2.5 统计前提检验规范（ADF / Breusch-Pagan / VIF）

在进行因子回归之前，必须依次执行以下三项前提检验。任何一项未通过，须按规则处理后方可继续。

**检验一：平稳性检验（ADF）**

```
ADF检验（Augmented Dickey-Fuller）：
├── 检验对象：所有时间序列——目标变量（利差）及所有因子变量
├── 原假设H₀：序列存在单位根（非平稳）
├── 判定标准：
│   ├── p ≤ 0.05 → 拒绝H₀ → 序列平稳 ✅
│   └── p > 0.05 → 无法拒绝H₀ → 序列非平稳 ❌
├── 处理规则：
│   1. 非平稳序列 → 执行一阶差分（ΔX_t = X_t - X_{t-1}）
│   2. 差分后重新执行ADF检验
│   3. 若差分后p≤0.05 → 使用差分后序列进行回归
│   4. 若一阶差分后仍p>0.05 → 标注"数据不满足平稳性假设"，跳过该因子
├── 输出格式：
│   ├── "利差序列：ADF统计量=-3.82, p=0.004 → 平稳 ✅"
│   ├── "宏观因子：ADF统计量=-2.15, p=0.22 → 非平稳 ❌ → 一阶差分后p=0.001 ✅"
│   └── "行业因子：一阶差分后ADF p=0.08 → 仍不平稳 ❌ → 该因子不可用，已跳过"
└── 标注位置：回归输出顶部标注
    "所有序列已通过ADF平稳性检验（或已作差分处理）"
```

**检验二：异方差检验（Breusch-Pagan）**

```
Breusch-Pagan检验：
├── 检验对象：回归模型的残差
├── 原假设H₀：残差方差为常数（同方差）
├── 判定标准：
│   ├── p > 0.05 → 无法拒绝H₀ → 同方差 ✅（使用普通标准误即可）
│   └── p ≤ 0.05 → 拒绝H₀ → 存在异方差 ❌
├── 处理规则：
│   ├── 存在异方差 → 必须使用Newey-West HAC标准误
│   └── 在回归输出中标注 "使用HAC标准误校正异方差"
├── 与β置信区间的关系：
│   └── 无论Breusch-Pagan结果如何，β置信区间统一使用Newey-West标准误
│       （HAC标准误在存在异方差和自相关时均保持一致，不依赖检验结果）
└── 输出格式：
    "Breusch-Pagan检验：BP统计量=18.5, p=0.002 → 存在异方差 ✅ 已使用HAC标准误"
```

**检验三：多重共线性检验（VIF）**

```
VIF（Variance Inflation Factor，方差膨胀因子）：
├── 检验对象：所有自变量（因子变量）
├── 计算方式：对每个因子，将其对其他所有因子做回归，VIF_j = 1/(1-R²_j)
├── 判定标准：
│   ├── VIF < 5 → 无显著共线性 ✅
│   ├── 5 ≤ VIF < 10 → 中度共线性 ⚠️
│   │   └── 标注"VIF=XX，中度共线性——该因子权重已降低"
│   └── VIF ≥ 10 → 严重共线性 ❌
│       └── 标注"VIF=XX，严重共线性——该因子与另一个因子高度重叠，已合并/删除"
├── 处理规则：
│   ├── VIF≥10 → 识别重叠因子对，合并或删除其一后重新计算VIF
│   ├── 合并方式：取两个因子的等权平均作为新因子
│   └── 记录处理过程以供追溯
├── 输出格式：
│   ├── "VIF检验：宏观因子=2.8, 行业因子=3.2, 区域因子=1.5 → 均<5 ✅"
│   └── "VIF检验：行业因子=8.5 ⚠️（中度共线性，权重已降低）"
└── 标注位置：回归诊断部分
```

**三项检验的集成输出规范：**

```
统计前提检验报告：
├── ADF平稳性检验：所有序列已通过（或经差分处理后通过） ✅
├── Breusch-Pagan异方差检验：BP=18.5, p=0.002 → 存在异方差
│   └── 处理：已使用Newey-West HAC标准误
└── VIF多重共线性检验：最大VIF=3.2 → 无显著共线性 ✅
```

#### 附录.2.6 相关性统计量的置信区间（Fisher Z变换）

```
Fisher Z变换计算相关系数的95%置信区间：
├── 步骤1：将Pearson r 转换为Fisher Z
│   Z = 0.5 × ln((1+r)/(1-r))
├── 步骤2：Z的抽样标准差
│   SE_Z = 1 / √(n-3)（n = 窗口期观测值数量，如24周）
├── 步骤3：Z的95%置信区间
│   CI_Z = [Z - 1.96 × SE_Z,  Z + 1.96 × SE_Z]
├── 步骤4：将CI_Z转换回相关系数尺度
│   CI_r = [(e^(2×CI_Z_low)-1)/(e^(2×CI_Z_low)+1),
│           (e^(2×CI_Z_high)-1)/(e^(2×CI_Z_high)+1)]

计算示例（r=0.62, n=24）：
  Z = 0.5 × ln((1+0.62)/(1-0.62)) = 0.5 × ln(4.263) = 0.725
  SE_Z = 1 / √(21) = 0.218
  CI_Z = [0.725 - 1.96×0.218,  0.725 + 1.96×0.218] = [0.298, 1.152]
  CI_r = [0.290, 0.818]

输出："ρ = 0.62 [95% CI: 0.29–0.82], n=24"
```

**相关性突变检测规则修订：**

```
旧规则：mean_ρ 周度变化 > 0.1 且 连续4周上升 → 预警
新规则：当前相关性与滚动窗口相关性之差的绝对值 > 2 × SE_Fisher
        → 标记为相关性突变
        → 其中 SE_Fisher = √(1/(n₁-3) + 1/(n₂-3))（两个窗口的标准误合并）

输出格式修订：
  旧：mean_ρ = 0.38（+0.05 vs 4周前）
  新：mean_ρ = 0.38 [95% CI: 0.25–0.51]（Δ=+0.05，|Δ| < 2×SE=0.12 → 未达突变阈值 ✅）
```

**相关性矩阵的置信区间标注：**

```
相关性矩阵中的每个ρ值附加置信区间：
  隆22-通22：ρ=0.62 [95% CI: 0.29–0.82]  n=24
  通22-天23：ρ=0.72 [95% CI: 0.44–0.88]  n=24
  隆22-晶澳：ρ=0.35 [95% CI: -0.07–0.66] n=24 ← CI跨越0，不显著

标注规则：
├── CI不包含0 → 标注 "显著相关 ✅"
└── CI包含0 → 标注 "不显著——可能为抽样误差 ❌"
```

**前提条件：** n ≥ 10（最小样本量要求，否则Fisher Z变换不稳定）；n < 10时标注"样本量不足，相关性估计不可靠——仅作方向性参考"。

### 附录.4 质量门禁：统计方法使用检查清单【统计修正 v0.3.1】

归并自 quantitative-analysis.md 附录D，作为本附录的质量门禁节；v0.11.2 起本节为单一事实源。

每次运行定量分析前，AI Agent 必须逐项确认以下统计前提条件。每项确认结果（✅ / ⚠️ / ❌）必须在输出中显式标注，不得省略。

```
□ 时间序列是否已做平稳性检验（ADF）？
   → 标注 "ADF p=X.XXX → 平稳/非平稳（已差分处理/跳过）"

□ 回归残差是否已做异方差检验（Breusch-Pagan）？
   → 标注 "BP p=X.XXX → 同方差/异方差（已使用HAC标准误）"

□ 多因子模型是否已做多重共线性检验（VIF）？
   → 标注 "最大VIF=X.X → 无共线性/中度共线性权重已降低/严重共线性已合并"

□ 相关性估计是否附带置信区间（Fisher Z变换）？
   → 标注 "ρ=X.XX [95% CI: X.XX–X.XX]"

□ 波动率估计是否附带置信区间（卡方分布）？
   → 标注 "HV=X.X% [95% CI: X.X%–X.X%]"

□ 利差估计是否附带置信区间（Bootstrap）？
   → 标注 "利差均值=X [95% CI: X–X]"

□ 多重假设检验是否做了FDR校正（Benjamini-Hochberg）？
   → 标注 "原始信号数=X，FDR校正后显著数=X，q=0.05"

□ 样本量是否≥30（最小回归样本量）？
   → 若 n<30，标注 "样本量不足（n=X）——回归结果仅作方向性参考"

□ 尾部概率是否标注为"排序工具"而非"精确概率"？
   → 标注 "尾部概率为排序工具，非精确统计概率"

□ 测试是否包含假阳性率和假阴性率（不能只用成功案例）？
   → 标注 "假阳性率估计：X%（经FDR校正），假阴性率估计：X%（基于检验功效）"
```

**使用规则：**
1. 在每次定量分析输出的末尾，必须附带此检查清单的完成状态
2. 未通过的项目必须附带处理说明——"未做"与"已做但未通过"的标注不同
3. 此清单是质量控制门禁——所有项目均为✅时，分析方可进入轨道B四级信号映射
